# H2-1骨格: 一人暮らし向けミールキットの選び方

## H3-1: 1〜2人前の少量から注文できるか確認する
- 結論(1文目): ミールキットは2人前からのサービスが多いため、一人暮らしなら1人前や少量注文に対応しているか最初に確認してください。[KW: ミールキット 一人暮らし]
- 根拠(2文目): 2人前を1人で食べると量が多すぎて残しやすく、冷蔵タイプは翌日までに食べきる必要がある。
- 追加情報: 1人前対応のサービス名は挙げず一般論で。2人前を2回に分けて食べる方法にも触れる。冷凍タイプなら分割保存しやすい点にも言及。
- パーツ: ul箇条書き → 確認すべき項目（1人前の有無 / 2人前の分割保存可否 / 冷蔵or冷凍の保存期間）
- strong締め: 注文画面で人数・食数を選べるか公式サイトで確認すれば、食べきれずに捨てる失敗を防げます。

## H3-2: 自炊頻度に合わせて冷蔵タイプ・冷凍タイプを選ぶ
- 結論(1文目): ミールキットには冷蔵と冷凍の2タイプがあり、一人暮らしの自炊頻度に合わせて使い分けると食材を無駄にしにくくなります。[KW: ミールキット 一人暮らし]
- 根拠(2文目): 冷蔵タイプは届いた日から2〜3日以内が消費期限の目安で、毎日自炊する人向き。冷凍タイプは1か月以上保存でき、週2〜3回だけ使いたい人に合っている。
- 追加情報: 冷蔵は野菜の食感が残りやすい。冷凍は長期保存できるがレンジ解凍や湯煎の手順が加わる。
- パーツ: ul箇条書き → 冷蔵タイプの特徴 / 冷凍タイプの特徴
- strong締め: 週に何回ミールキットを使うか決めてからタイプを選ぶと、届いた食材を余らせずに使い切れます。

## H3-3: 1食あたりの送料込み実質単価で比較する
- 結論(1文目): 一人暮らし向けミールキットの費用を比べるときは、商品代金だけでなく送料を含めた1食あたりの実質単価で計算してください。[KW: 一人暮らし ミールキット 安い]
- 根拠(2文目): 送料は注文金額や配送エリアで変わるサービスが多く、商品が安くても送料込みだと割高になるケースがある。
- 追加情報: 1食500〜900円が相場帯。送料無料条件も確認。年会費・出資金の有無にも触れる。
- パーツ: ul箇条書き → 比較時に含めるべき費用（商品代金 / 送料 / 年会費・出資金 / 入会特典・割引）
- strong締め: 公式サイトの料金ページで送料条件まで確認すれば、月々の食費が想定外に増えるのを防げます。

## H3-4: 配送エリア・受け取り方法（置き配・店頭）を確認する
- 結論(1文目): ミールキットの宅配サービスは配送エリアが全国対応でない場合があり、一人暮らしの住所が対象かどうか申し込み前に確認してください。[KW: ミールキット 一人暮らし]
- 根拠(2文目): 生協系は地域限定が多い。不在がちな一人暮らしは置き配・宅配ボックス・店頭受取の対応も重要。
- 追加情報: 置き配はクール便非対応のサービスもある。ヤマト・佐川は時間帯指定可。自社配送は曜日固定が多い。
- パーツ: ul箇条書き → 確認すべき受け取り条件（配送エリア / 置き配対応 / 時間帯指定 / 自社配送かヤマト等か）
- strong締め: 公式サイトで郵便番号を入力すれば配送対象かどうか調べられます。

## H3-5: 定期/都度・スキップ条件で続けやすさを判断する
- 結論(1文目): ミールキットを一人暮らしで続けるには、注文の自由度が高いサービスを選ぶのが安全です。[KW: ミールキット 一人暮らし]
- 根拠(2文目): 定期コースはスキップや一時停止ができないと、出張や旅行で受け取れないときも届いてしまう。都度購入は自由度が高いが単価が上がる場合がある。
- 追加情報: スキップの締め切り日も確認ポイント。解約金・最低利用回数の有無。
- パーツ: ul箇条書き → 確認すべき条件（定期/都度の有無 / スキップ・一時停止の可否 / 締切日 / 解約金・最低回数）
- strong締め: スキップや一時停止がアプリやWeb上で完結するサービスなら、予定が変わっても食材を無駄にせずに済みます。
