# H2-4骨格: 一人暮らしがミールキットを使う前に知っておく注意点

## H3-23: 2人前単位のサービスは1食分が多すぎて食べきれないことがある
- 結論: 2人前から→一人暮らしだと食べきれない
- 根拠: 冷蔵タイプは消費期限が短い→廃棄リスク
- 対策: 冷凍タイプ / 2回に分けて食べる / 1人前サービスを探す
- strong: 1人前対応か分割保存可能かを申し込み前に確認

## H3-24: 少量注文だと送料が上乗せされて1食あたりが割高になる
- 結論: 少量注文→送料負担割合が大きい
- 根拠: 注文金額一定以下で送料発生
- 対策: まとめ注文 / 自社配送のサービス選択
- strong: 送料無料条件を先に調べておけば出費を抑えられる

## H3-25: まとめ買いすると一人暮らし用の冷凍室に入りきらなくなる
- 結論: まとめ買い→冷凍庫パンク
- 根拠: 一人暮らし用冷蔵庫は冷凍室が小さい
- 対策: 空きスペース確認 / 1回3〜5食 / 配送頻度を上げる
- strong: 注文前に冷凍庫の空きを確認→入りきらない失敗を回避
