# 骨格: H2③ 糖尿病の食事管理に宅配弁当を利用するメリット

## H3① カロリー・糖質の計算を任せられる
- 結論(1文目): 宅配弁当を利用すると、1食ごとのカロリー・糖質・塩分の計算を管理栄養士に任せられます。
- 根拠(2文目): 食事制限では毎食の栄養成分を正確に計算する必要がありますが、宅配弁当なら栄養計算済みの状態で届きます。
- 追加情報: 食品の栄養成分表示を見ながら毎食計算する手間がなくなり、栄養管理を継続しやすくなる。
- パーツ: ul → カロリー計算不要 / 糖質量が明記されている / 塩分量も管理されている
- strong締め: 栄養計算にかかっていた時間を、食事以外の健康管理や自分の休息に使えるようになります。

## H3② 毎日の献立づくり・買い物の負担が減る
- 結論(1文目): 宅配弁当なら献立を考える必要がなく、食材の買い出しや調理の時間も省けます。
- 根拠(2文目): 食事制限に対応した献立を毎日考えるのは手間がかかり、仕事や家事と並行して続けるのは大変です。
- 追加情報: 冷凍で届くので電子レンジで温めるだけで済む。
- パーツ: なし
- strong締め: 献立づくりや買い物に使っていた時間を、仕事や家族と過ごす時間に充てられるようになります。

## H3③ 離れて暮らす親の食事の心配や見守りの負担が減る
- 結論(1文目): 宅配弁当を利用すれば、離れて暮らす親に栄養管理された食事を届けられます。
- 根拠(2文目): 遠方に住む家族の食事を毎日管理するのは難しいですが、宅配弁当なら定期便で栄養バランスの整った食事を届け続けられます。
- 追加情報: 全国配送対応なら地域を問わず利用でき、冷凍便なので保存がきく。
- パーツ: ul → 全国配送対応サービスが多い / 定期便で届く / 冷凍だから保存がきく
- strong締め: 定期便を手配しておけば、離れていても親の食事管理を無理なく続けられます。
