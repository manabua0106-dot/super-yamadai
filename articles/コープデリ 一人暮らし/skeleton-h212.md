# 骨格 H2⑫：コープデリを一人暮らしで始めるなら食費の試算と向き不向きの確認から（まとめ）

**タイプ**：まとめ（H3なし・3〜5文・writing-manual §A-5／h3-templates「まとめH2のテンプレート」準拠）
**約束**：食費の試算と向き不向きの確認→お試しへ、の行動で締める。CTA[コープデリ]と末尾免責をここに配置。

## 骨格

```
[1文目] <strong>結論の要約（メインKW「コープデリ」「一人暮らし」含む）</strong>
  - 論点：コープデリが一人暮らしで割高になるかは、毎週の注文金額（手数料の無料ライン）と量の頼み方で決まる
  - H2②（食費試算）・⑦⑧（向き不向き）の要約。新しい角度＝「申し込む前に自分の食費で試算する」行動視点
  - 数値は出さない（週198円・無料ライン額はH2②の実額表に一本化済み。本文の言い直し禁止＝§G-4）

[2文目] 補足（読者の判断基準）
  - 論点：向き不向きの再確認＝買い物時間を減らしたい・重い物を届けてほしいなら向く／
    1食ずつ買いたい・受け取り時間を選びたいなら合わない（⑦⑧の要約を1文で・列挙しすぎない）

[3文目] <strong>具体的な次のアクション</strong>
  - 論点：おためしセットで味と量を確かめてから加入を判断する行動促し
  - 深掘りはしない（/774未登録のため着地のみ＝outline内部リンク運用条件）
  - 「お試しセットあり（内容は時期により変動）」の表現はservice-info.md「WEB限定おためしセットあり」に整合

[CTA] [コープデリ]（ショートコード1行・最終行）

[末尾免責ブロック]（CTA後・§E-11集約）
  - 手数料・無料になる注文金額・お試しセットの内容や価格は変わる場合があるため各公式サイトで要確認（有利誤認の担保）
  - 記事内の価格・手数料は2026年7月時点の公式サイト確認情報
  - 掲載内容は編集部基準による（医療助言系の免責は本記事は疾病名なしのため不要）
```

## 数値と裏取り元

- **このH2では新規の数値を出さない**（週198円・無料ライン6,000円/11,000円等はH2②の実額表が唯一の掲載箇所。まとめで繰り返さない）
- 免責の「2026年7月時点」＝outline裏取り日（2026-07-24 公式確認）に基づく
- お試しセットの言及＝service-info.md #19「WEB限定おためしセットあり（内容・価格は時期により変動）」の範囲内。具体価格は書かない
