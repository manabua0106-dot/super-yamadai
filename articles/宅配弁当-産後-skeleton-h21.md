# H2① 骨格：産後の宅配弁当を選ぶときに確認するポイント

## H3① 1食あたりの実質単価と1ヶ月の総額を計算する

- 結論(1文目): 産後の宅配弁当を選ぶときは、1食あたりの単価に送料を加えた実質コストで比較すると失敗を防げます。
- 根拠(2文目): 商品代金が安くても送料が高ければ、1ヶ月の総額が予算を超える場合がある。
- 追加情報: 1食単価×食数+送料=1ヶ月の総額。産後は1日1〜2食×30日を想定するとシミュレーションしやすい。
- パーツ: ul → 商品代金（1食あたり）、送料（都度or定期で異なる場合あり）、まとめ買い割引の有無、定期コースの割引率
- strong締め: 公式サイトで1食あたりの単価と送料を確認し、1ヶ月分の総額を計算してから申し込むと予算オーバーを防げます。

## H3② 冷凍タイプか常温（毎日配達）タイプかを決める

- 結論(1文目): 産後の宅配弁当には冷凍タイプと冷蔵の毎日配達タイプがあり、生活スタイルに合わせて選ぶのが失敗しにくい方法です。
- 根拠(2文目): 冷凍は長期保存とまとめ買いができるが冷凍庫スペースが必要。冷蔵は毎日届くため保存スペースは不要だがエリアが限定される場合がある。
- 追加情報: 産後のワンオペ育児では、まとめて届く冷凍タイプの方が受け取り回数を減らせる。一方、冷蔵は解凍不要ですぐ食べられる。
- パーツ: ul → 冷凍タイプ（長期保存OK、まとめ買いで送料節約、全国配送が多い）、冷蔵タイプ（毎日届く、解凍不要、保存スペース不要、配送エリアが限られる場合あり）
- strong締め: 冷凍庫の空きスペースと配送エリアの両方を確認してからタイプを決めると、届いてから困る事態を避けられます。

## H3③ 配送エリアと置き配・不在時の受け取り方法を確認する

- 結論(1文目): 産後の宅配弁当を注文する前に、自宅が配送エリア内かどうかと受け取り方法を確認しておくのが安全です。
- 根拠(2文目): サービスによって配送エリアや対応する配送業者が異なる。産後は在宅でも赤ちゃんの世話でインターホンにすぐ対応できない場面が多い。
- 追加情報: 置き配対応の有無、宅配ボックス利用可否、日時指定の時間帯数。不在時の再配達は産後の負担になりやすい。
- パーツ: ul → 配送エリア（全国or地域限定）、日時指定（何時間帯から選べるか）、置き配・宅配ボックス対応、不在時の対応（再配達or翌配送）
- strong締め: 公式サイトで郵便番号を入力して配送エリアを確認し、置き配や日時指定の条件も一緒にチェックできます。

## H3④ 栄養成分と添加物の情報を公式サイトで確認する

- 結論(1文目): 産後の宅配弁当を選ぶ際は、栄養成分表示と添加物の方針を公式サイトで確認しておけば食事選びの判断材料になります。
- 根拠(2文目): 授乳中はカロリーやたんぱく質、鉄分を意識したい時期。添加物の使用方針はサービスごとに異なり、公式サイトで確認するのが確実。
- 追加情報: 栄養成分表示の見方（1食あたりのカロリー・たんぱく質・塩分等）。無添加を謳うサービスでも、保存料の方針は公式サイトで確認する必要あり。
- パーツ: ul → カロリー、たんぱく質、塩分、脂質、添加物の方針（保存料・着色料等は公式サイト参照）
- strong締め: 公式サイトの栄養成分表示ページで1食あたりのカロリーや塩分を確認すれば、授乳中の食事管理の目安になります。

## H3⑤ 上の子も食べられるメニューがあるか確認する

- 結論(1文目): 産後に上の子（幼児）がいる場合は、大人と一緒に食べられるメニューがある宅配弁当を選ぶと食事の準備がまとめて済みます。
- 根拠(2文目): 上の子用に別の食事を用意するのは産後のワンオペ育児では大きな負担になる。
- 追加情報: おかずの味付け（薄味かどうか）、おかず数の多いコース（大人と子どもで分け合える）、ごはん付きの有無。
- パーツ: ul → おかずの味付け（幼児も食べられるか）、おかず数（多いほど分け合いやすい）、ごはん付きの有無、アレルギー対応の有無
- strong締め: おかず数が多いコースやごはん付きセットを選べば、上の子と分け合いやすく産後の食事準備が1回で済みます。
