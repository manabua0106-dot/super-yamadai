# 骨格: H2① 糖尿病向け宅配弁当の選び方

## H3① 医師の指示に合ったコース（カロリー制限・糖質制限）があるか
- 結論(1文目): 宅配弁当を選ぶ際は、医師から指示されたカロリーや糖質の基準に合ったコースがあるサービスを探してください。
- 根拠(2文目): カロリー制限食と糖質制限食では栄養設計の方向性が異なり、自分の食事制限に合わないコースを選ぶと栄養管理がうまくいかない場合があります。
- 追加情報: カロリー制限食→1食のカロリーを一定範囲に抑えたメニュー。糖質制限食→糖質量を一定値以下に抑えたメニュー。医師の指示内容を確認してから選ぶ。
- パーツ: ul → カロリー制限食の特徴 / 糖質制限食の特徴 / 医師の指示を確認するタイミング
- strong締め: 医師から指示されたカロリーや糖質の基準値をメモしてから公式サイトで比較すると、自分に合ったコースを見つけやすくなります。

## H3② 配送エリアと受け取り方法が生活に合っているか
- 結論(1文目): 冷凍の宅配弁当は全国配送に対応しているサービスが多く、地域を問わず利用しやすくなっています。
- 根拠(2文目): 一部のサービスでは離島や特定地域が配送対象外のため、注文前に配送エリアの確認が必要です。
- 追加情報: 日時指定・配送頻度の選択肢もサービスごとに異なる。離れて暮らす家族に届ける場合は届け先の住所確認を。
- パーツ: ul → 配送エリア / 日時指定の可否 / 配送頻度 / 届け先の郵便番号確認
- strong締め: 公式サイトの配送エリア検索で届け先の郵便番号を入力すれば、対象エリアか確認できます。

## H3③ 美味しく続けられるメニュー数や味付けの工夫があるか
- 結論(1文目): 宅配弁当を長期間続けるには、メニュー数が多く味付けに工夫のあるサービスを選んでください。
- 根拠(2文目): 制限食は味が単調になりやすいイメージがありますが、和洋中のメニューを揃えたサービスなら毎日の食事に変化をつけられます。
- 追加情報: メニューを自分で選べるか/おまかせか。好き嫌いが多い場合はメニュー選択可のサービスが向いている。
- パーツ: ul → メニュー数 / 自分で選べるか / 和洋中の有無 / 新メニュー追加の有無
- strong締め: 公式サイトのメニュー一覧を確認し、好みの味付けのメニューがあるサービスを選ぶと続けやすくなります。

## H3④ 安く続けられるか（1食あたり価格＋送料込み月額で比較）
- 結論(1文目): 宅配弁当の費用を比較するときは、1食あたりの価格だけでなく送料を含めた月額の総費用で判断すると失敗しにくくなります。
- 根拠(2文目): 1食の単価が安くても送料が高いサービスでは、月額で見ると割高になる場合があります。
- 追加情報: 定期コースで送料無料になるサービスや、まとめ注文で1食単価が下がるサービスもある。月に何食注文するか決めてから月額計算。
- パーツ: ul → 1食あたり価格 / 送料 / 月額総費用 / 定期購入の割引 / 初回特典
- strong締め: 1日1食を30日間利用する場合の月額（1食単価×30＋送料）を計算すれば、予算に合ったサービスを見つけやすくなります。

## H3⑤ 合併症（腎臓病・透析）に対応したコースがあるか
- 結論(1文目): 合併症でたんぱく質や塩分にも制限がある場合は、たんぱく調整食や腎臓病食のコースがあるサービスを選ぶ必要があります。
- 根拠(2文目): カロリーや糖質に加えてたんぱく質・カリウム・リンの制限が必要な場合、通常の糖質制限コースでは対応できません。
- 追加情報: たんぱく調整食を扱うサービスもあり、コースの栄養基準で対応可否を判断できる。合併症がある方は医師に相談してからコースを決める。
- パーツ: ul → たんぱく質制限 / 塩分制限 / カリウム制限 / 医師への相談
- strong締め: 合併症がある場合は医師の指示を確認し、対応コースの栄養基準を公式サイトで比較してから申し込んでください。
