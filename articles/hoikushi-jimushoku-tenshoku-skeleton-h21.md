# H2① 骨格: 保育士から事務職への転職は未経験でもできる

## H2導入文（2〜3文）
- 保育士から事務職への転職は、未経験でも十分に実現できる
- 事務職は異業種からの転職者を受け入れている求人が多い職種
- ただし年代によって選考で重視される点が異なるため、自分の立ち位置を把握しておく必要がある

1. 事務職は未経験歓迎の求人が多く応募しやすい

### H3-1: 事務職は未経験歓迎の求人が多く応募しやすい

- 結論(1文目): 事務職は未経験歓迎の求人が多く、保育士から転職する場合も応募先に困りにくい【KW: 保育士から転職 事務職 / 共起語: 求人、未経験】
- 根拠(2文目): 一般事務・営業事務・医療事務など事務職の種類は幅広く、業界を問わず募集がある
- 補足情報: 事務職に必要なパソコンスキルは入社後の研修で身につけられる企業も多い。保育園での仕事で培ったコミュニケーション能力や書類作成の経験は、事務の実務でも評価される
- パーツ: ul → 一般事務（データ入力・電話対応・書類整理）、営業事務（見積書・請求書の作成・顧客対応）、経理事務（伝票処理・経費精算）、医療事務（受付・レセプト業務）
- strong締め: 「事務職の種類を知っておくだけで、自分に合った求人を見つけやすくなります。」【1文目の「応募先に困りにくい」と角度を変え、具体的行動に】

### H3-2: 20代は伸びしろで評価されるが30代以降は即戦力が求められる

- 結論(1文目): 保育士から事務職に転職する場合、20代は伸びしろを評価されやすく、30代以降はスキルや資格で即戦力を示す必要がある【KW: 保育士から転職 / 共起語: 理由、挑戦】
- 根拠(2文目): 20代は異業種への挑戦を前向きに評価する企業が多い一方、30代以降はExcel操作や簿記など具体的な実務スキルを求められる傾向がある
- 補足情報: 30代・40代でも、MOSや簿記3級を取得してから応募すると書類選考の通過率が上がる。年代別の戦略の違いを知っておくだけで準備の方向性が定まる
- パーツ: ul → 20代の戦略（ポテンシャル採用を狙う・未経験歓迎の求人を中心に探す）、30代の戦略（資格を取得してから応募する・保育士経験を事務スキルに変換してアピールする）、40代の戦略（専門性の高い事務職を選ぶ・パソコンスキルを証明する資格を先に取る）
- strong締め: 「自分の年代に合った準備を進めれば、未経験からでも事務職の内定を取れる可能性は十分にあります。」【1文目の年代別評価と角度を変え、読者の背中を押す】
