# H2④ 宅配弁当を利用するときの注意点 骨格

## H3① 送料を含めた総額は自炊より高くなりやすい
【H3骨格】id="chuui-souryou" 送料を含めた総額は自炊より高くなりやすい
- 結論(1文目): 宅配弁当は商品代金に送料を加えると、自炊と比べて1食あたりの費用が高くなる傾向があります。[KW:宅配弁当]
- 根拠(2文目): 自炊の1食あたりの材料費は200〜400円程度ですが、宅配弁当は1食500〜900円に送料が上乗せされるため、月20食で月額1万〜2万円の差が生まれるケースがあります。
- 追加情報: 送料はサービスや地域によって1回あたり780〜2,500円まで差があり、毎週届く定期コースだと月の送料だけで3,000〜10,000円になる場合もあります。
- パーツ: 注意mybox(赤) → 送料を抑える方法: まとめ注文（10食・20食プラン）で1配送あたりの送料を分散する / 送料無料条件のあるサービスを選ぶ / 定期コースの送料割引を利用する
- マーカー: 「1食あたり○○円」の表示だけで判断せず、送料と合計した月額で比較してみてください。
- strong締め: 各サービスの公式サイトで送料を確認し、月あたりの総額を計算してから申し込むと想定外の出費を防げます。
- 共起語: 送料、自炊、1食あたり、月額

## H3② 冷凍庫の空きスペースを事前に確認する
【H3骨格】id="chuui-reitouko" 冷凍庫の空きスペースを事前に確認する
- 結論(1文目): 冷凍宅配弁当をまとめて受け取る場合、冷凍庫に十分な空きスペースがないと入りきらない可能性があります。[KW:冷凍宅配弁当]
- 根拠(2文目): 宅配弁当の容器サイズは1食あたり縦16〜18cm×横20〜23cm×高さ3〜4cm程度で、7食セットでも冷凍庫の棚1段分を占めます。
- 追加情報: 一人暮らし用の冷蔵庫（冷凍室30〜40L）では7食が限度になるケースもあるため、注文食数を調整する必要があります。
- パーツ: 注意mybox(赤) → 冷凍庫に入りきらない場合の対策: 注文食数を7食以下にする / 配送頻度を毎週にしてストック量を減らす / 冷凍庫の無料レンタルに対応しているサービスを利用する
- マーカー: 注文前に冷凍庫を開けて、弁当容器が何個入るか実測してみてください。
- strong締め: 注文前に冷凍庫の空きスペースを確認し、入りきる食数でプランを決めれば届いた弁当が入らないトラブルを防げます。
- 共起語: 冷凍庫、冷凍弁当、食数

## H3③ 初回割引後の通常価格にギャップがある
【H3骨格】id="chuui-waribiki" 初回割引後の通常価格にギャップがある
- 結論(1文目): 宅配弁当の初回割引やお試し価格は通常価格より大幅に安いため、2回目以降の料金を事前に確認してください。[KW:宅配弁当]
- 根拠(2文目): 初回30〜50%OFFで申し込んだ場合、2回目から通常価格に戻り、1食あたり200〜400円の差額が生じるサービスがあります。
- 追加情報: 定期コースの割引が初回のみなのか、継続しても適用されるのかはサービスごとに異なります。累計購入数に応じて割引率が上がる仕組みや、定期コースでいつでも一定割合の割引が適用されるサービスもあります。
- パーツ: なし
- マーカー: なし
- strong締め: 申し込み前に2回目以降の料金と解約条件を公式サイトで確認しておけば、想定より高くなるのを防げます。
- 共起語: 定期コース、お試し、通常価格、解約

## H3④ ご飯付きかおかずのみかを事前に確認する
【H3骨格】id="chuui-gohan" ご飯付きかおかずのみかを事前に確認する
- 結論(1文目): 宅配弁当にはおかずのみのサービスとご飯付きのサービスがあり、注文前にどちらなのかを確認してください。[KW:宅配弁当]
- 根拠(2文目): おかずのみのサービスが多数派で、ご飯は自分で用意する必要があります。「届けば食事が完結する」と想定していると、白米やパンを別途準備する手間が発生します。
- 追加情報: ご飯付きプランを用意しているサービスもありますが、おかずのみのプランより1食あたり100〜200円ほど高くなる傾向があります。
- パーツ: なし
- マーカー: おかずのみのサービスを選ぶ場合、パックごはんをまとめ買いしておくと手間を減らせます。
- strong締め: 公式サイトでおかずのみかご飯付きかを確認し、ご飯の準備方法もあわせて決めておくと届いた日からスムーズに利用できます。
- 共起語: ご飯付き、おかずのみ、白米
