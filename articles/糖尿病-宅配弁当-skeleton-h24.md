# 骨格: H2④ 糖尿病向け宅配弁当を利用するときの注意点

## H3① 宅配弁当だけで1日の栄養管理が完結するわけではない
- 結論(1文目): 宅配弁当は1食分のおかずが中心で、ごはんや間食のカロリー・糖質管理は別途必要です。
- 根拠(2文目): 宅配弁当だけで1日の食事をまかなえると考えてしまうと、ごはんの量や間食で全体のカロリーや糖質が基準を超える場合があります。
- 追加情報: ごはんの量は医師や管理栄養士の指示に従う。間食もカロリー・糖質を確認してから選ぶ。
- パーツ: ul → ごはんの量は医師の指示に従う / 間食のカロリー・糖質も確認 / 1日トータルの栄養管理が大切
- strong締め: 医師から指示された1日の摂取基準をもとに、宅配弁当＋ごはん＋間食の合計で栄養管理を行うと、食事全体のバランスを保ちやすくなります。

## H3② 冷凍庫の空きスペースを事前に確認する
- 結論(1文目): 冷凍宅配弁当をまとめて注文する場合は、届く前に冷凍庫のスペースを確認してください。
- 根拠(2文目): 7食〜21食セットで届くサービスが多く、一人暮らし用の小型冷凍庫だと入りきらない場合があります。
- 追加情報: 容器サイズは公式サイトに記載されている。注文前に冷凍庫の空きを測っておく。
- パーツ: ul → 容器サイズの確認 / 冷凍庫の空きスペースの計測 / 注文食数の調整
- strong締め: 注文前に冷凍庫の空きスペースと容器サイズを比較しておくと、届いた後に保管場所で困る失敗を避けられます。

## H3③ 医師の指示と合わないコースを選ばない
- 結論(1文目): 宅配弁当のコースを選ぶ際は、医師から指示されたカロリー・糖質・塩分の基準値を確認してから申し込んでください。
- 根拠(2文目): 「糖質制限」「カロリー制限」の基準値はサービスやコースごとに異なり、医師の指示と合わないコースを選ぶと栄養管理がうまくいかない場合があります。
- 追加情報: 合併症がある場合はたんぱく質やカリウムの制限も確認。不安なら担当医に相談してからサービスを決める。
- パーツ: ul → 医師の指示書を確認 / コースの栄養基準を公式サイトで確認 / 不安なら担当医に相談
- strong締め: 医師の指示書やメモを手元に用意してからコースの栄養基準を比較すると、自分に合ったコースを選びやすくなります。

## H3④ 制限食は味が薄いと感じる場合がある
- 結論(1文目): 塩分やカロリーを制限した宅配弁当は、普段の食事と比べて味が薄いと感じる方もいます。
- 根拠(2文目): 塩分を抑えたメニューでは、濃い味付けに慣れている方は物足りなさを感じやすくなります。
- 追加情報: 出汁や香辛料で味に深みを出しているサービスもある。お試しセットや初回割引で実際の味を確認してから定期コースに申し込むと失敗しにくい。
- パーツ: ul → 出汁・香辛料で味付けを工夫しているサービスもある / お試しセットや初回割引で味を確認 / 口コミで味の傾向を調べる
- strong締め: お試しセットや初回割引で実際の味を確認してから定期コースに切り替えると、味のミスマッチで後悔しにくくなります。
