# 裏取り結果（2026-07-29 公式アクセス）

貼付ドラフトに含まれていた数値の検証結果。**◯＝本文で使える／×＝削除（根拠なし）／△＝断定を避ける**。

## ◯ 使える（公式で確認済み）

### 手数料（コープみらい東京エリア・個人宅配）

出典：[コープデリ公式 ご利用手数料について（東京都）](https://efriends.coopdeli.jp/look/shipping/)

| 1回の利用金額 | 基本手数料 | 配送手数料 |
|---|---|---|
| 6,000円以上（税別） | 0円 | 0円 |
| 6,000円未満（税別） | 88円（税込） | 110円（税込）＝合計198円 |
| 商品配達がない週 | 88円（税込）のみ | ― |

- 2人グループは6,000円未満でも88円のみ、3人以上グループは無料
- **公式に「今後手数料制度の改定を予定しております」と告知あり → 末尾免責に必須**

### 割引制度（申請制）

出典：[コープデリ公式 赤ちゃん・子育て割引](https://efriends.coopdeli.jp/look/feature/child/)／[ご利用手数料（東京都）](https://efriends.coopdeli.jp/look/shipping/)

- 赤ちゃん割引：妊娠中〜1歳未満、申請から1年間、利用金額にかかわらず無料（コープみらい）。茨城・栃木・群馬・長野は申請から2年間、新潟は3歳未満まで
- 子育て割引：1歳〜小学校入学前。3,000円以上（税別）で無料、3,000円未満は198円（コープみらい）
- シルバー割引：世帯全員または2人世帯のいずれか1人が65歳以上 → 基本手数料88円のみ（配達手数料0円）
- ふれあい割引：組合員本人または同居家族が障害者手帳を持っている → 基本手数料88円のみ
- 自然災害割引：り災証明書の交付を受け、交付日から1年以内 → 0円
- **新規加入特典：加入後8週間は利用手数料が無料**
- コープみらい限定：月の注文金額12,000円以上（税別）で手数料相当をポイント還元
- 申請には組合員コードと母子健康手帳・マイナンバーカード等の画像が必要

### 留守置き（置き配）

出典：[公式FAQ No.4224](https://faq.coopdeli.jp/faq/show/4224)／[No.6914](https://faq.coopdeli.jp/faq/show/6914)

- 事前に玄関先などの場所を指定すれば留守置きで届く
- 冷凍・冷蔵品はドライアイスや保冷剤と一緒に保冷容器へ入れる
- 箱を覆う「コープデリカバー」を無料で貸出（希望者・問い合わせフォームから申込）
- 留守置きの申込・相談は電話 0120-608-217

### 脱退

出典：[公式FAQ No.4542](https://faq.coopdeli.jp/faq/show/4542)／[No.4440](https://faq.coopdeli.jp/faq/show/4440)／[No.4541](https://faq.coopdeli.jp/faq/show/4541)

- eフレンズ（ネット）で脱退手続きはできない
- 脱退手続きは利用中の生協（コープみらい東京/埼玉/千葉・いばらきコープ・とちぎコープ・コープぐんま・コープながの・コープデリにいがた）ごとの窓口
- 脱退手続き後、**2週間程度**で指定口座に出資金（預け金）を返金（利用代金を支払い済みの場合）

### お試しセット

出典：[公式 WEB限定おためしセット](https://efriends.coopdeli.jp/look/webtrial/)

- 3種類（人気バラエティセット＝冷凍食品10品／本格中華セット＝5品／すくすく子育てセット＝冷凍離乳食）
- 送料無料・カタログ同梱・支払いはクレジットカードのみ
- 申込から3〜5日以内にクール宅急便で届く（宅配業者の指定は不可）

### すでに組合員の場合

出典：[公式FAQ No.4539](https://faq.coopdeli.jp/faq/show/4539)

- コープのお店・コープ共済ですでに出資金を払っている場合、宅配利用のために改めて加入・出資は不要
