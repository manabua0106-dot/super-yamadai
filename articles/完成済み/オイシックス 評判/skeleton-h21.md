# 骨格 H2① オイシックスの評判は食材の質が好評で料金に不満が多い

**タイプ**：その他（全体像・リード）／**H3なし**
**約束**：最初に評判の全体像を結論で言い切り、この記事で口コミ・ひどい/高い/勧誘の噂・続く人とやめる人の違いを確かめられると導く。導入1文＋メリット/デメリット簡易表で全体像を示す。表＝編集部の総括、③④＝実在口コミの引用と役割を分け同じ文言を繰り返さない。「結論から解説します」等のメタ宣言は使わない。

## 構造（上から順）

1. 導入結論文（1〜2文・各60字以内・メインKW「オイシックスの評判」を含む・見出しの丸写しにしない）
2. メリット/デメリット簡易表（2列。左＝好評ポイント／右＝不満ポイント。各3〜4を名詞句で・句点なし・§学び30準拠）
3. 導き文（1文・この記事で何を確かめられるかを予告。メタ宣言・「結論から解説します」不使用）

※このH2にはCTA・比較テーブル・画像・ショートコードは置かない（CTAはH2⑩の[Oisix]に一本化・outline「CTA・パーツ配置」）。
※strong締めは任意。全体像リードのため無理に付けず、付けるなら導き文を具体行動（お試しで味と量を確かめる）に寄せる。空strong禁止（§D-5）。

## PREP骨格

- **P（結論・1文目）**：オイシックスの評判は、食材の質や時短を評価する声が多い一方で、料金や量への不満も見られる、と全体像を1文で言い切る。※見出し文言をそのままコピーせず角度を少し変える（見出し＝「質が好評で料金に不満」／本文＝「質・時短が好評／料金・量に不満」で情報を1点足す）。
- **R/E（表で提示）**：好評・不満の内訳を簡易表で可視化（下記「表の中身」）。本文で表の項目を同じ文言で繰り返さない（§G-3・§B-2）。
- **P（導き文）**：口コミ（良い/気になる）、ひどい・高い・勧誘の噂、続く人とやめる人の違いを、この記事で事実ベースに確かめられると読者に予告する。

## 表の中身（編集部の総括・名詞句・③④の口コミ文言と重複させない）

| 好評のポイント | 不満のポイント |
|---|---|
| 帰宅後すぐ調理できる時短性 | 自炊やスーパーより割高 |
| 届く野菜や果物の鮮度 | 量が少なく感じる商品がある |
| 献立決めと買い物の手間が減る | 不要な商品が自動カートで届くことがある |
| 普段作らない料理でレパートリーが増える | お試し後に勧誘の連絡が来ることがある |

- 好評4点＝facts §4-1のクラスタ（時短9件／新鮮4件／手間減4件／レパートリー4件）を名詞句に総括。
- 不満4点＝facts §4-2の担当H2振り分け（⑥割高N1/N2・④量N3/N4・⑤自動カートN7・⑨勧誘N8）を名詞句に総括。
- 表はあくまで編集部総括。各不満の実口コミ引用・事実回収は担当H2（④⑤⑥⑨）で行い、ここでは深掘りしない（dedupe・🚨12）。
