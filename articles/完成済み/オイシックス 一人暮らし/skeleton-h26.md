# 骨格 H2⑥ オイシックスを使った一人暮らしの良い口コミ

**タイプ**：口コミ（h3-templates v5「口コミ解説H3」準拠・§A-7）
**約束**：実際に一人暮らしで使った人の良かった声を事実として示す。blockquote＋cite・原文ママ。素材はoutline末尾「口コミ素材」節のG1〜G3をそのままコピペ。
**H2直下**：導入1〜2文のみ（口コミH2のためolは置かない方針で統一。何の口コミを何件載せるかを示す）。
**全体注意**：
- blockquoteはoutlineのG1〜G3を1文字も変えずコピペ（改変・要約・肩書き付与禁止）
- 口コミの言い換え文・blockquote再説明・「〜との声があります」型メタ説明は書かない（学び35）
- 「悪い口コミ」呼称は次H2⑦の話。本H2は「良い口コミ」のままでOK
- 補足事実の数値はservice-info.md（Oisixエントリ）とoutline「数値・事実の裏取り済みデータ」のみ。推測数値禁止
- 健康系の補足は付録1 #3に注意（「栄養バランスの整った食事がとれる」はNG）

- 伝える事実（口コミの言い換え以外の新情報）：
  1. なぜ初心者でも作れるか＝Kit Oisixはカット済み・下味付きの食材とレシピがセットで、20分以内で主菜と副菜が完成する（裏取り元：service-info.md #16 strong1文目の方向性・費用欄）。

- パーツ設計：導入1文 → blockquote(G1) → 補足の文2文（PREP的に：仕組み→効果）。ul不要（列挙3項目なし）。

- 重複ガード：H2②（Kit Oisixのコース紹介）と角度を分ける。ここは「初心者でも作れる仕組み」1点のみ、コース選びの話はしない。

## H3-3 買い物のストレスと食材ロスが減った

- 引用する口コミ：素材G3（@kiiinooo・2022年5月21日・https://x.com/kiiinooo/status/1527843864987729920）を原文ママコピペ。
- 導入1文：仕事帰りの買い物と食材の余りに悩んでいた一人暮らしの人の口コミ、と示す。
- 伝える事実：
  1. なぜ買い物が減るか＝定期宅配は毎週・隔週・4週に1回から選べ、日時指定で自宅に届く（裏取り元：service-info.md #16「配送日時の設定」欄）。
  2. なぜ食材ロスが減るか＝ミールキットは使う分量だけ入って届くため、一人暮らしで余らせがちな半端な食材が出にくい。
- パーツ設計：導入1文 → blockquote(G3) → 補足の文2文（買い物→ロスの順）。ul不要。
- strong締め候補：なし（配送頻度の数字は事実1の文中で出す。strongで言い直さない）。
- 重複ガード：H2③「余らせない使い方」（冷凍・まとめ買い等のコツ）とは角度が違うことを維持。ここは「届く仕組みでロスが減った体験」、H2③は「読者が実践するコツ」。H2④「献立を考えなくてよくなる」とメニューのワンパターン脱出の話が近いので、口コミ原文（メニューもワンパターンから抜け出せて）以上の解説は足さない。
