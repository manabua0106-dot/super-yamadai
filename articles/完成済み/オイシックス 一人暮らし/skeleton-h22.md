# 骨格：H2② 一人暮らしに向いているオイシックスのコース

**タイプ**：選び方（h3-templates v5「選び方系 H3」準拠・情報インベントリ方式）
**約束**：数あるコースのうち、一人暮らしが選ぶべきものを結論で示す
**執筆前の必須裏取り**（outline「執筆時の要裏取りリスト」）：
- Kit Oisix・おいしいものセレクトコースの現行の正式名と1食・1セット単価（公式 oisix.com）
- パッとOisix（1人前冷凍弁当）は2026年に縮小・終了情報あり → **本H2では扱わない**（古い競合記事の推しは採用しない。現行有無の言及はFAQ H2⑨に一本化＝重複回避）
- 定期コースの種類変更・毎回の中身入れ替え可否（公式で確認）

## H2直下（導入文1〜2文＋ol）

- 導入文の論点（リスク・必要性から入る）：
  1. オイシックスの定期コースは複数あり、選ぶコースで届く中身が変わる
  2. 一人暮らしの生活（自炊の頻度・献立を考えたいか）に合わないコースを選ぶと、食材が余りやすい
- ol（liはH3見出しと完全一致）：
  1. 献立を考えたくない人は献立つきのKit Oisix
  2. 食材を自分で選びたい人はおいしいものセレクトコース
- ※「献立つき／自分で選ぶ」の切り分けはこの導入で1文だけ示し、詳細は各H3へ（先取りしない）

## H3-1：献立を考えたくない人は献立つきのKit Oisix

■ 伝える事実
  1. 【結論】献立を考えるのが面倒な一人暮らしには、レシピつきミールキットのKit Oisixが向いている
  2. 【根拠】カット済み・下味つきの食材とレシピがセットで届き、主菜と副菜が20分以内で完成する（strong 1文目の方向性＝service-info.md #16）
  3. 【具体】1セット2〜3人前中心・1セット1,500〜3,000円台（税込）＝service-info.md #16 費用欄の値のみ使用
  4. 【具体】2人前を一人暮らしで使う場合は2食分に分けられる（半分は翌日に回す詳細はH2③に譲る＝1文で触れるに留め深掘りしない）
  5. 【具体・要裏取り】1食あたりの目安額（outlineの「Kit Oisix 1食約540円〜」は執筆時に公式で最終確認。確認できなければ書かない）

■ パーツ設計
  - 事実1・2 → 文（PREP：結論→理由「〜からです」）
  - 事実3〜4 → 文（数値はservice-info.mdからコピペ・言い換えない）
  - ulは使わない（列挙が3項目未満。埋めるためのulを作らない）

■ 結論(1文目案の骨子)：「毎日の献立を考えたくない一人暮らしには、献立つきミールキットのKit Oisixが向いています。」（複合KW「一人暮らし」含む）

■ strong締め：任意。付けるなら「2人前を2食に分ける」等の具体的な使い方 or 1食あたり額（裏取りできた場合のみ）。H2④H3「毎日の献立を考えなくてよくなる」（生活変化）と角度を分ける＝ここは**コースの中身・選ぶ基準**に限定し、生活がどう変わるかは書かない

■ 数値と裏取り元
  - 1セット1,500〜3,000円台（税込・2〜3人前中心）→ service-info.md #16
  - 20分以内で主菜と副菜が完成 → service-info.md #16 strong 1文目の方向性
  - 1食約540円〜 → outline裏取りメモ（執筆時に公式で最終確認。§F-4・確認不可なら不掲載）

■ 共起語：ミールキット／献立／レシピ／時短

## H3-2：食材を自分で選びたい人はおいしいものセレクトコース

■ 伝える事実
  1. 【結論】食材を自分で選んで自炊したい一人暮らしには、おいしいものセレクトコースが向いている
  2. 【根拠】旬の野菜や定番食材の提案をベースに、カートの中身を毎回自由に入れ替えて注文できる（※提案内容・入れ替え仕様は公式で要裏取り。自動カート仕様は articles/オイシックス 評判/facts.md をRead）
  3. 【具体】使う分だけ選べば2〜3人前キットを余らせずに済み、少量の野菜・日配品も単品で足せる（仕様の細部は要裏取り）
  4. 【対比】Kit Oisixとの違い＝「献立ごと届く」か「食材を選んで届く」か（1文のみ。H3-1の言い直しをしない）

■ パーツ設計
  - 事実1・2 → 文（PREP）
  - 事実3 → 文
  - 事実4 → 文1つ or 2列ミニ表（学び45：対になる情報は表が読みやすい）。**表にする場合**は「Kit Oisix＝献立つき・20分調理／おいしいものセレクト＝食材を自分で選ぶ」の2行対比のみ（価格は入れない＝H3-1既出・H2①とも重複させない）

■ 結論(1文目案の骨子)：「食材を自分で選んで料理したい一人暮らしには、おいしいものセレクトコースが向いています。」

■ strong締め：任意。付けるなら「定期でもコースは後から変更できる」等の具体的な行動（変更可否は公式で要裏取り。確認できなければstrong省略）

■ 数値と裏取り元
  - コースの正式名・提案内容・カート入れ替え仕様 → **公式oisix.comで要裏取り**（outline要裏取りリスト＋articles/オイシックス 評判/facts.md）
  - 価格数値はこのH3では書かない（H2①の実額表・H3-1と重複させないため）

■ 共起語：定期コース／注文／カート／自炊

## このH2で書かないこと（重複防止メモ）

- 送料・1ヶ月の総額 → H2①に一本化（このH2で金額比較をしない）
- 余らせない具体的な使い方（冷凍・作り置き・まとめ買い） → H2③に一本化（H3-1で「分けられる」と1文触れるのみ）
- 献立を考えなくてよくなる生活変化 → H2④に一本化（ここはコース選択の判断基準まで）
- パッとOisix（1人前冷凍弁当）の現行有無 → FAQ H2⑨に一本化
- おためしセットの案内 → H2⑧に一本化
