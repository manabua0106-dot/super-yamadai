## 法令セーフ変換チェック（執筆時に必ず適用）
| 変換対象 | 変換後 |
|---------|--------|
| 管理栄養士が監修 | 管理栄養士が献立設計に関与 |
| 栄養バランスの整った食事がとれる | 栄養成分表示を確認しながら食事を選べる |
| 高たんぱく（効果として） | たんぱく質量やカロリー量の異なるメニューから選べる |
| 低糖質（効果として） | カロリーや糖質に配慮した |
| ダイエット向け（本文） | カロリーや糖質に配慮したコース |
| 制限食 | 栄養成分に配慮したコース |
| 〇〇%OFF（条件なし） | 〇〇%OFF※条件を同一文内に併記 |
| 送料無料（条件なし） | 対象プランで送料無料（条件併記） |
