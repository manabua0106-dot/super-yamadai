# 骨格 H2① 毎日届く宅配弁当の選び方

## H2導入文（リスク・必要性）
- 各社で配送頻度や対応エリアが異なるため、選び方を間違えるとエリア外で利用できないか希望と違うサービスに登録してしまう
- 4つの観点で比較すると失敗を防ぎやすい

## ol一覧（H3と完全一致）
1. 配送頻度と保存タイプ(冷蔵か冷凍か)で選ぶ
2. 配送エリアと配達方法(手渡し・置き配)で選ぶ
3. 1食あたりの料金と送料で選ぶ
4. 利用目的(高齢者向け・一人暮らし・栄養配慮)で選ぶ

### H3-1: 配送頻度と保存タイプ(冷蔵か冷凍か)で選ぶ
- P: 毎日届く宅配弁当を選ぶなら、まず冷蔵で平日毎日届くタイプか、冷凍まとめ配送タイプかを決める
- R: 受け取り体制と冷凍庫の容量によって向き不向きが変わる
- E: 冷蔵毎日配達の代表はワタミの宅食、コープデリ、まごころ弁当、宅配クック123、配食のふれ愛、ライフデリ、ニコニコキッチン。冷凍まとめ配送はDr.つるかめキッチン、Meals、タイヘイ、オイシエ、ベネッセのおうちごはん、ワタミの宅食ダイレクト、nosh
- strong: 在宅時間と冷凍庫の空き容量から、冷蔵毎日か冷凍ストックかを最初に絞り込みます

### H3-2: 配送エリアと配達方法(手渡し・置き配)で選ぶ
- P: 毎日届く宅配弁当は配達対象エリアと配達方法が選択を左右する
- R: 自社配送網の有無で対応エリアが大きく違うため、希望のサービスがエリア外なこともある
- E: 自社配送はワタミの宅食(北海道・青森・岩手・秋田・鳥取・沖縄を除く)、コープデリ(1都6県限定)。フランチャイズ店舗ベースは宅配クック123・配食のふれ愛・まごころ弁当・ライフデリ・ニコニコキッチン。冷凍便はヤマトクール冷凍便等で全国対応
- strong: 公式サイトで郵便番号を入力して、配達対象エリアかどうか申込み前に必ず確認します

### H3-3: 1食あたりの料金と送料で選ぶ
- P: 毎日届く宅配弁当は1食あたり単価と送料を合計した実質負担額で比較する
- R: 公式の単価表示と実際の支払額が異なる場合があるため
- E: 冷蔵毎日配達は送料無料の代わりにエリアが限定的(ワタミの宅食・コープデリ・まごころ弁当)。冷凍便は単価が安くても送料が上乗せ(Dr.つるかめキッチンは定期で送料無料、Meals・noshは食数別、ワタミの宅食ダイレクトは送料880円〜)
- strong: 1食単価×食数+送料の合計額をエクセルなどで並べて、月額の総額で比較します

### H3-4: 利用目的(高齢者向け・一人暮らし・栄養配慮)で選ぶ
- P: 毎日届く宅配弁当は利用目的によって最適な選択が変わる
- R: 高齢者は安否確認・やわらか食、一人暮らしは少量と保存性、栄養配慮はカロリー・塩分・たんぱく質の調整可否で見るべき軸が違う
- E: 高齢者向けは宅配クック123・配食のふれ愛・まごころ弁当・ライフデリ。栄養配慮はDr.つるかめキッチン・タイヘイ・ベネッセ。一人暮らしは1食360円〜のワタミの宅食ダイレクトや量を絞った舞菜ミニ弁当(コープデリ)が向く
- strong: 利用者の状況とコース内容を照らし合わせ、初回お試しや少量セットから始めると失敗しにくくなります

## チェック観点

- strong締めは具体的な行動で締める
- ulリストを各H3に1つ入れる(8割目安)
- 「として」「という」「指示語」回避
