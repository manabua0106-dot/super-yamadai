# H2① 選び方 骨格（ゲート2）

## H2導入文

- 1文目（リスク）：会社ごとに価格帯・同梱内容・対象エリア・継続の仕組みが大きく異なる
- 2文目（具体的リスク）：価格の安さだけで選ぶと通常価格との差や対象エリア外で受け取れない問題に気付きにくい
- 3文目（対策予告）：下記の観点を順に押さえてから申し込むのが安全
- olリスト：4項目（H3と完全一致）

## H3①-1 お試しセットの価格と内容で比較する

- 結論(1文目): ミールキットのお試しセットは、1食あたりの税込単価と同梱食品数の両方を見比べるのが安全
- 根拠(2文目): 同じ約1,980円でもOisixと伊勢丹DOORでは中身の構成比が違う
- 追加情報(3-4文目): Oisixは10品以上のバランス型、ヨシケイは1食300円〜の5日分献立
- パーツ: ul → 比較項目（単価・品数・人数・送料）
- マーカー: 数字を表に並べると同じ軸で評価しやすくなる
- strong締め: 公式サイトの商品ページで品数と税込総額を並べて確認すれば中身の差を把握できる
- 1文目とstrong締めの角度差: 1文目=比較の軸の指定 / strong=具体的なアクション+効果
- 共起語: セット・価格・内容・食材・比較・レシピ

## H3①-2 配送エリアと配送方法を確認する

- 結論(1文目): ミールキットのお試しセットは対象エリア外だと注文できないため、申込前の郵便番号検索が先決
- 根拠(2文目): Oisix・らでぃっしゅぼーや・伊勢丹DOORは全国配送、コープデリは関東・甲信越1都8県、パルシステムは1都11県
- 追加情報(3文目): ヨシケイは自社便の平日手渡し、置き配BOX無料貸出
- パーツ: ul → エリア・便種・置き配・再配達
- マーカー: 通勤前後の受け取りには時間帯指定と置き配条件まで確認
- strong締め: 郵便番号検索で先に確かめると申込後のエリア外エラーで時間を無駄にしない
- 1文目とstrong締めの角度差: 1文目=何を確認すべきか / strong=確認方法と結果
- 共起語: エリア・配達・全国・地域・宅配・時間

## H3①-3 お試し後の継続価格と送料を確認する

- 結論(1文目): ミールキットのお試しセットは通常価格から大幅値引きのため、継続利用時の月額総額も先に把握しないと予算が想定外になる
- 根拠(2文目): 通常のKit Oisixは1人前約800〜1,500円、らでぃっしゅぼーやは送料が注文金額で変動
- 追加情報(3文目): ヨシケイは自社便で送料無料、コープ・パルは加入組合と注文金額で手数料変動
- パーツ: ul → 通常価格・送料条件・配送頻度・スキップ解約ルール
- マーカー: お試し価格の安さだけで選ぶと継続後に予算オーバーが起きやすい
- strong締め: 通常コース価格と送料条件を合算して月額総額をお試し前に試算すれば食費の想定外を防げる
- 1文目とstrong締めの角度差: 1文目=なぜ必要か / strong=具体的な計算方法
- 共起語: 価格・定期・コース・送料・キャンペーン・必要

## H3①-4 勧誘の有無と退会のしやすさを確認する

- 結論(1文目): ミールキットのお試しセットは申込前に勧誘頻度と退会手順を公式FAQで確認すると安心
- 根拠(2文目): Oisix・らでぃっしゅぼーや・伊勢丹DOORはオンライン完結の単発購入で追加手続き不要
- 追加情報(3文目): コープ・パルは生協加入制で退会時に組合員番号と連絡先を電話または申請書で伝える
- パーツ: ul → 勧誘頻度・加入区分・マイページ退会・退会後受け取り
- マーカー: 加入制サービスは退会手続きに1週間前後かかるため次の配達締切日も確認
- strong締め: ヘルプページで勧誘方針と退会フローを先に読むとお試し後のしつこい連絡で困るトラブルを避けられる
- 1文目とstrong締めの角度差: 1文目=何を確認するか / strong=方法と効果
- 共起語: 注文・安心・チェック
