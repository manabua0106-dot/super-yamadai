## 共起語の配置先

| 共起語 | 配置先 | 使い方 |
|---|---|---|
| 送料込み | 導入文3文目／H2①早見表の列名／H2①H3③ | 「送料込みの1食あたり」の形で使う |
| 1食あたり | H2①早見表・H2①H3③・H2⑤H3② | 金額とセットでのみ |
| 12食 | H2①（H3①〜④すべて）・FAQ① | 条件を固定する語として毎回添える |
| まとめ買い割引 | H2①H3④・H2④H3② | デリピックスの割引名として。率の表は置かない（値段記事の資産） |
| 初回割引 | H2⑤H3② | ナッシュの1,500円OFF／1,000円OFF／500円OFF |
| 糖質 | H2③H3①・H2③H3③・早見表「栄養の基準」行 | 「平均30g以下」「30g以下」を書き分ける |
| たんぱく質 | H2③H3②・H2④H3③ | デリピックス側の基準として。ナッシュ側には書かない（公式に記載なし） |
| 塩分 | H2③H3③・早見表 | ナッシュ側の基準（2.5g以下）として |
| 冷凍 | 導入文1文目・H2①H3①・FAQ④ | 「冷凍宅配弁当」「冷凍庫」の形 |
| レンジ | H2②導入の引用の地の文（レンジ5分） | 1回だけ。温め時間の詳細はお試し記事の資産 |
| メニュー | H2②H3③・H2⑤H3①・FAQ③ | ナッシュ側の「100種類以上から選べる」を軸に |
| 献立 | H2②H3①②・H2④H3① | デリピックス側の「提案された献立」を軸に |
| シェフ | H2②H3①・H2④導入・まとめ | 「星つきレストラン出身のシェフが献立づくりに関わった」の範囲を出ない |
| 配送エリア | 早見表・H2⑤H3③ | 沖縄の話は早見表とH2⑤H3③の2箇所だけ |
| 定期便 | H2①H3④・FAQ④ | デリピックスの「定期便」表記に合わせる |

## 置かない語（あえて外す）

| 語 | 理由 |
|---|---|
| 容器サイズ・温め時間の詳細 | ナッシュ側が公式に未記載で比較にならない（outline 裏取り#6） |
| 添加物・保存料 | ナッシュ側を裏取りできず、非訴求社への一方的な攻撃になる |
| 1食分の野菜 | 公式の注記（全冷凍弁当の平均値で計算）が落ちると誤読を招く（outline 裏取り#12） |
| nosh club・492円 | 条件が公式に明記されていない（outline 裏取り#5） |
| おすすめ◯選・ランキング | 既存の多社比較記事3本とカニバリする |
