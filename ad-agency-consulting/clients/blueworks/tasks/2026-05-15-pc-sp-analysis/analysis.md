## 結論（3行）

1. **SPはクリック量が多くCVRが極端に低い**（PC 2.86% vs SP 0.39%、PCの1/7）
2. **主要ボトルネックは「情報収集クエリ × SP × PC向けLP」の三重苦**。LP最適化（SP）が最有力
3. **最優先アクション**：(1) SP版LP改善 (2) SP非指名KWの入札-100% (3) PC側フレーズ一致拡張

## 2. 仮説5つの網羅検証

| # | 仮説 | 結果 | 根拠 | 必要な追加確認 |
|---|---|---|---|---|
| 1 | 計測欠落（特にSP） | ❌ **棄却** | SP「blue works 税理士 法人」で1CV発生。完全欠落ではない | 電話CV設定の有無のみ要確認 |
| 2 | 検索意図差（B2Bでありえる） | △ **部分成立だが決定的ではない** | SPは情報収集系（無料相談）が多いが、PCも同じ語が上位。両デバイスとも非指名はCVRが低い | - |
| 3 | LP最適化（SP版） | ⚠️ **最有力。未検証** | キャンペーン名「マイクロ法人LP**(PC)**」がPC向けLP想定。SP最適化されていない可能性大 | PageSpeed Insights / GA4 デバイス別エンゲージメント / LPの実物確認 |
| 4 | オーディエンス差（18-24等） | ⚠️ **未検証** | 年齢別データ未取得 | デバイス×年齢クロス取得 |
| 5 | キャンペーン構造相違 | ❌ **棄却** | PC/SP同一キャンペーン「マイクロ法人LP(PC)」から配信。構造差なし | - |

### 仮説2の補足

PC/SPで「クエリの構成比」は似ているが、**CVRに7倍の差**がある。これは検索意図差では説明しきれない。
→ **「同じクエリでもSPでCVしない」=デバイス×LPの問題**。

### 仮説3が最有力な理由

- キャンペーン名にPC指定（「マイクロ法人LP(PC)」）
- 指名検索ではSPでもCVする → ユーザーは「BlueWorksに依頼したい」と思えば手段問わず行動する
- 非指名（情報収集）ユーザーは、SP上で「初見の長文LP」を読み切らずに離脱している可能性
- → **SPユーザーは「指名でCVするかLPで離脱するか」の二極化**

## 3. 最終結論

### ボトルネック構造

```
SPユーザー（517クリック・大半が情報収集系）
   ↓
PC向けに設計されたLPに着地
   ↓
情報収集段階のユーザーがSPで長文LPを読みきらない
   ↓
SP CVR 0.39%（PCの1/7）
```

### 「悪化」判定（feedback-log.md の判定フレームに従う）

| 基準 | 判定 |
|---|---|
| CPA基準（全体） | 改善（完全一致化前¥5万→後¥2-3万） |
| ボリューム基準 | 悪化（CV絶対数減） |
| デバイス別効率 | **PC: 良好（CPA¥24,213）／ SP: 悪化（CPA¥88,419）** |
| 目標達成度 | 未達（5月Google CV 1件、目標未公開だが議事録で「全然足りない」） |
| トレンド | 改善中（CPA下降）× ボリューム不足 |

→ **「全体は改善、ただしSPに引きずられて目標未達」が正確な表現**。

## 4. アクション（優先度順）

### 🔴 P1：今週中に実行

#### A1. SP配信の入札-100%またはキャンペーン分割（即実行可）

- **何を**：「マイクロ法人LP(PC)」キャンペーンのSPデバイス入札を**-100%**（停止扱い）
- **どれくらい**：1キャンペーン
- **いつまでに**：2026-05-16（即日）
- **成功基準**：消化額のうちSP分（直近¥1,547/日）が¥0に近づき、PC配信に予算が回る
- **根拠**：SP CPA¥88,419はPCの3.7倍。同予算でPC配信すればCV4件分の予算でPC約7-8件のCVが見込める計算

⚠️ ただし、これは「攻めの停止」。**SP用LP改善（A3）を準備しないと中長期で機会損失**。

#### A2. 電話CV計測の有無確認・設定（最優先）

- **何を**：Google広告の「目標」 → コンバージョンアクション一覧確認
- **どれくらい**：1チェック
- **いつまでに**：2026-05-16
- **成功基準**：電話CVが設定されていれば現状OK。未設定なら追加設定タスク化
- **根拠**：税理士業界はSP→電話流入が一定ある。フォームCVだけだとSP CVが構造的に過小評価される可能性

### 🟡 P2：来週〜再来週

#### A3. SP版LP改善（最重要・中期）

- **何を**：「マイクロ法人LP(PC)」のSP版LPを別途用意 or 現LPのSP表示を抜本改善
- **どれくらい**：1パターン
- **いつまでに**：2026-05-29
- **成功基準**：SP CVR 0.39% → 1.0%以上（PCの1/3水準まで）
- **改善ポイント候補**（要GA4・PageSpeedで裏取り）：
  - ファーストビューを「無料相談」訴求に変更（SPユーザーは情報収集段階）
  - フォームを上部に配置（または電話CTA・LINE CTAを上部に）
  - 表示速度の改善（PageSpeed Insights SP 80以上目標）
  - ページ長を短縮（SPは縦スクロール多）

#### A4. PC側のフレーズ一致拡張

- **何を**：PC側で当たり指名KWの周辺をフレーズ一致で拡張
- **どれくらい**：5-10語
- **いつまでに**：2026-05-22
- **成功基準**：PC CV月10件以上（現状4件/45日）
- **根拠**：PC CVR 2.86%は十分良好。ボリューム不足だけが課題

#### A5. SP非指名KW の入札調整

- **何を**：A1で全停止しない場合の代替案。SPで「税理士 無料 相談」「税理士 事務 所」など非指名・情報収集系の入札を-50〜-80%
- **どれくらい**：5-10語
- **いつまでに**：2026-05-22
- **成功基準**：SP CPA改善（¥88K → ¥50K以下）

## 6. ボトルネックを定量で示すコミュニケーション案

クライアント側のプロが見ても納得する書き方：

```
SP: 19,451表示 / 517クリック / 2CV / CVR 0.39% / CPA ¥88,419
PC:  3,572表示 / 140クリック / 4CV / CVR 2.86% / CPA ¥24,213

→ クリック量はSPが3.7倍、しかしCVRは1/7。
→ 同じクエリ構成でこの差なので、検索意図差より「デバイス×LPフィット」が支配的。
→ SP配信の費用効率を上げるには、(a)SP側のLP改善か、(b)SP配信絞り込み（一時停止含む）か、の二択。
→ 推奨は「(b)で予算をPC側に寄せて即座にCV増 → 並行でSP LP改善 → SP再投下」の二段構え。
```
