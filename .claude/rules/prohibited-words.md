## このファイルの役割

このファイルは **lint.sh / 各 checker が grep するための語彙テーブル** です。
ルールの解釈・背景は `writing-manual.md` が正本。本ファイルはあくまで検査用の実装層。

矛盾が生じた場合は writing-manual.md が優先されます。

## レイヤー1

### 1-a：完全禁止（機械検出＝ERROR・必ず修正）

| 禁止語 | 修正方法 |
|---|---|
| 体言止め（「〜を実施。」「〜に対応。」等） | 「〜しています。」「〜です。」「〜できます。」で締める |
| することができます | 「できます」 |
| 指示語（この / その / これ / それ / こうした / そうした） | 具体的な名詞に置き換える。例外は下記の「指示語の例外」のみ |
| 無責任系語尾（〜とされています / 〜ようです / 案内されています / 〜とのこと / 〜と思われます / 〜と見られます） | 事実は言い切る（「〜です」「〜になります」）。公式で裏取りできないなら書かない |
| 見出し（H2/H3）内の（） | 見出しに補足の（）を入れない。情報は本文へ。本文の nosh（ナッシュ）等はOK |

> 2026-06-29 再改定：指示語は「やっぱり禁止」に戻した（ライフミール記事で「この特別価格」「その後は」等が頻発し読みにくくなったため）。完全禁止に伴う不自然さは、下記の例外と「口コミ（blockquote）内は検査対象外」で回避する。

### 1-b：努力義務（2026-06-29 緩和・lintはWARNING）

下記は**禁止ではない**。lint は WARNING を出すが、文脈で自然なら使ってよい。
ただし**極力、具体的な名詞・動詞に置き換える努力をする**（空の文・回りくどい言い換えを増やさないことが目的）。

| 語 | できれば |
|---|---|
| として | 具体的な表現に書き直す（自然なら可） |
| という / といった | 直接記述／「〜や〜など」に（自然なら可） |
| 強調用の「」（会話文・固有名詞・口コミ以外） | 強調目的の「」は使わない。lintはWARNING（誤検出しやすいため一読して判断） |

> 背景：「という/として」を完全禁止にすると「との」等の不自然な代替を誘発し、かえって文章が固く・空っぽになるため、努力義務に留める。

### 指示語の例外（許容）

- 「この記事では」→ OK
- 「この口コミのように」「この口コミの方は」→ OK（直前の引用を指す）
- 「そのまま」「そのもの」→ OK（副詞・限定用法）
- 「そのため」→ OK（接続詞用法）
- 「それぞれ」→ OK
- **口コミ（blockquote）内の指示語は一切対象外**（原文ママのため改変しない）

### ⚠️ 2026-04 改訂で除外

以下は過去に完全禁止だったが、v4.0 から**使用OK**：

- **こと**（名詞化）→ 自然な日本語として必要な場面がある
- **〜しましょう / 確認しましょう** → 通常文の行動喚起として OK

### カテゴリE：過去事故ログ（同じ間違いを繰り返さない）

- 「8週間で120種類のメニューが届く」→ 根拠なし。「メニューは定期的に入れ替わるため、同じ料理が続きにくい」に修正
- 「お試し8食6,307円」→ 公式サイトで確認不可。「お試しセットあり（内容は時期により異なる・公式で要確認）」に修正
- 「送料990円（地域別）」→ 正しくは「送料990円〜（食数別）」
- 「医師が献立を監修」→ 過誇張。「専門医の指導のもと管理栄養士が献立を監修」に修正
- 価格改定の見落とし多発 → **service-info.mdの価格のみを使う。記憶や外部ソースから補完しない**

### カテゴリG：制限あり

| 表現 | ルール |
|---|---|
| 「〜い。」で終わるアドバイス文 | 「〜です。」「〜できます。」「〜してください。」で締める。「〜いです。」はOK |
| 「」（カギ括弧） | 会話文・固有名詞・読者心理描写のみ。強調目的では使わない |
| おすすめです | 記事内3回以内 |
| 根拠のない具体数字 | 出典URLで裏取りできない数字は使用禁止 |
| 「〜とされています」「一般的に〜」 | 裏取りできないなら書かない |
