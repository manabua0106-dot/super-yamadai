## このファイルの役割

食材宅配・宅配弁当ジャンル固有の**法令FB（景表法・薬機法・健康増進法）**を蓄積する場所。
Manabuさんからの指摘・gensparkチェックで引っかかった事案・過去事故を記録する。

### 運用フロー

```
1. 法令チェックで引っかかった / Manabuさんから指摘
   ↓
2. このファイルに日付付きで追記
   ↓
3. パターン化できたら
   ↓
4. writing-manual.md 付録1（法令セーフ変換表）に昇格
   ↓
5. 過去事故ログとしてこのファイルの末尾に残す
```

### 記録フォーマット

```markdown
## YYYY-MM-DD: 事案のタイトル

### 事案N: 簡潔なルール名

- NG表現: 具体的な NG 例
- OK表現: 具体的な OK 例
- **法令**: 景表法・薬機法・健康増進法のどれか
- **記事**: 該当記事名
- **指摘元**: Manabuさん / genspark / gensparkログ
- **昇格判断**: 付録1に昇格するか、ここで留めるか
```

## 現在の蓄積

### writing-manual.md 付録1 に昇格済みの10パターン

※ 詳細は writing-manual.md 付録1 を参照。

1. 管理栄養士が監修 → 献立設計に関与
2. 専門医の指導のもと → 削除 or「監修者情報は公式サイト参照」
3. 栄養バランスの整った食事がとれる → 栄養成分表示を確認しながら食事を選べる
4. 〇〇%OFF・送料無料（条件なし） → 条件併記
5. 初回半額 → 初回限定の割引キャンペーンあり
6. 制限食・食事制限向け → 栄養成分に配慮したコース
7. 糖尿病向け・〇〇病向け → カロリーや糖質に配慮した
8. 国産食材100%・無添加 → 主要食材に国産品を使用
9. 100種類以上のメニュー（固定値） → 記事確認時点で・時期により変動
10. ダイエット向け・筋力アップ向け → たんぱく質量やカロリー量の異なるメニュー

## 過去事故ログ（writing-manual.md 付録2 カテゴリE からコピー）

同じ間違いを繰り返さないための記録：

### 事故1: 「8週間で120種類のメニューが届く」

- **NG**: 根拠なし（公式サイトで確認不可）
- **OK**: 「メニューは定期的に入れ替わるため、同じ料理が続きにくい」
- **教訓**: 数値は必ず公式サイトで裏取り

### 事故2: 「お試し8食6,307円」

- **NG**: 公式サイトで確認不可
- **OK**: 「お試しセットあり（内容は時期により異なる・公式で要確認）」
- **教訓**: 確認できない価格は書かない

### 事故3: 「送料990円（地域別）」

- **NG**: 実は「食数別」だった
- **OK**: 「送料990円〜（食数別）」
- **教訓**: 送料の計算方法を正確に確認する

### 事故4: 「医師が献立を監修」

- **NG**: 過誇張
- **OK**: 「専門医の指導のもと管理栄養士が献立を監修」
- **教訓**: 景表法・優良誤認。肩書きは正確に

### 事故5: 価格改定の見落とし多発

- **NG**: 記憶や外部ソースから価格を補完
- **OK**: `service-info.md` の価格のみを使う
- **教訓**: service-info.md が唯一の正（SSOT）
