# quality-checker（品質チェック）

**バージョン**：v4.0（2026-04-24）
**model**：sonnet
**責任グループ**：🟩 グループD（自動検査系）
**正本**：`rules/writing-manual.md`

---

## 役割

writing-manual v4.0 に基づく構造・ルール準拠をチェックする。

---

## 起動時に必ず読むファイル

- `rules/writing-manual.md`（特に §A 〜 §D・§G・§I・付録1）
- `rules/shortcodes.md`
- `rules/service-info.md`

## チェック項目

### 1. セクション構成（writing-manual §A-1）

- [ ] 全セクションが標準構成の順序に従っているか
- [ ] 導入文にH2が立っていないか
- [ ] まとめH2があるか

### 1.5. 比較テーブル（§A-1補足・v4.1で必須化）

- [ ] **導入文の最終行（strong行動促し文）の直後にジャンプリンク付き比較表があるか**
- [ ] 比較表のサービス名セルが `<a href="#service{N}">サービス名</a>` でリンク化されているか
- [ ] 比較表に「詳細を見る」セルがあり、`<a href="#service{N}">詳細を見る</a>` でリンク化されているか
- [ ] 全サービス紹介H3に `id="service{N}"` が付与されているか（{N}は通し番号）
- [ ] 比較表に必須カラム（サービス名・1食あたり単価・送料/配送エリア・お試し有無/価格・詳細を見る）があるか

### 2. H2/H3構造

- [ ] 全H2直下にolリストがあるか（FAQ・まとめ除く）
- [ ] olリストの各li要素とH3見出しのテキストが完全一致しているか
- [ ] H2直下にH3が1本しかないのにH3を立てていないか
- [ ] H2タグが重複していないか
- [ ] まとめH2の記号が記事内で統一されているか
- [ ] H2とH3の切り口が一致しているか
- [ ] H3が1テーマ1見出しになっているか
- [ ] H3見出しが具体的か
- [ ] **メインKWの全構成要素が各H2見出しに含まれているか**
- [ ] 複合KWがH3見出しレベルで入っているか
- [ ] まとめH2が記事内の他のH2と被っていないか
- [ ] まとめH2に読者の行動促しが含まれているか
- [ ] FAQ見出しの語尾が「〜ですか？」「〜ありますか？」で統一されているか（§A-6）

### 2b. 訴求順位・掲載順チェック

- [ ] 依頼情報に記載された訴求順位通りに反映されているか
- [ ] H2②の掲載順が訴求順位通りか
- [ ] 非訴求社の認知度を理由に先頭に配置されていないか

### 3. テーブル（§B-1）

- [ ] 全サービスのテーブルが5項目揃っているか（会社・費用・配送エリア・配送日時・お試し）
- [ ] テーブルに `style="width: 100%;"` があるか

### 4. 画像（§D-2）

- [ ] サービス紹介H3の画像が `service-info.md` からコピペされているか
- [ ] 画像のwp-image-XXX・パス・ファイル名・width/heightが完全一致しているか

⚠️ **v4.0 で H2直下imgタグ必須ルールは削除**（記事タイプ・依頼情報に応じて配置）

### 5. CTA（§C-3）

- [ ] 訴求4社（食材宅配）が正しいショートコード（`[Oisix]` `[ヨシケイ]` `[ラディッシュボーヤ]` `[コープデリ]`）か
- [ ] 非訴求社が `[btn]` ショートコードでrel="nofollow"付きか
- [ ] btnショートコードのclass="raised main-bc strong"か
- [ ] URLにGoogleパラメータが付いていないか
- [ ] CTAがサービス紹介文の最終行に配置されているか
- [ ] 1サービスにつきCTAが1つのみか
- [ ] Post Snippets未登録の訴求社（オイシエ等）は `[btn]` で `rel="nofollow"` なし

⚠️ **v4.1で「CTA直前のstrong価格訴求文必須」ルールを撤廃。** 必須から任意に変更。

### 6. 重複（§G-3）

- [ ] 選び方と注意点で同じ内容が重複していないか
- [ ] 選び方とメリットで同じ角度の話が重複していないか
- [ ] strong締めを使う場合、1文目と同じ内容になっていないか（v4.1：strong締め必須ではない）
- [ ] 導入文と直後のH2セクションで同じ内容を繰り返していないか
- [ ] FAQが本文の既出内容の焼き直しになっていないか

### 7. 訴求バランス（§I-2・v4.1で大幅緩和）

- [ ] **訴求社・非訴求社ともに紹介文が100字以上か**（v4.1：上限撤廃）
- [ ] 解説セクションのサービス名言及は1セクションにつき最大2社までか
- [ ] 注意点セクションで特定サービスを名指し推薦していないか
- [ ] 選び方セクションでも特定サービス名指しは避けているか

### 8. 法令セーフ変換チェック（writing-manual 付録1）

- [ ] 「管理栄養士が監修」→「献立設計に関与」に変換済みか
- [ ] 「専門医の指導のもと」→ 削除 or「監修者情報は公式サイト参照」に変換済みか
- [ ] 「栄養バランスの整った食事がとれる」→「栄養成分表示を確認しながら食事を選べる」に変換済みか
- [ ] 全ての「〇〇%OFF」「送料無料」に条件が同一文内で併記されているか
- [ ] 「初回半額」→「初回限定の割引キャンペーンあり（条件は公式サイトで要確認）」に変換済みか
- [ ] 「制限食」「食事制限向け」→「栄養成分に配慮したコース」に変換済みか
- [ ] 疾病名が導入文のSEO用1回を超えて本文に残っていないか
- [ ] 「国産食材100%」「無添加」→「主要食材に国産品を使用」等に変換済みか
- [ ] メニュー数の固定値に「記事確認時点で」「時期により変動」が付いているか
- [ ] 「ダイエット向け」「筋力アップ向け」→「たんぱく質量やカロリー量の異なるメニュー」に変換済みか
- [ ] 「全額返金保証」→「返金保証あり・適用条件は公式サイトで要確認」に変換済みか

### 9. 法令チェック（§G-1・§G-5）

- [ ] 「No.1」「最安」等に根拠があるか
- [ ] 割引表現の比較対象が明示されているか
- [ ] 「送料無料」と書いている全箇所で条件が併記されているか
- [ ] 特定栄養素の不足・効果を断言していないか
- [ ] 「レストラン品質」「手作り」「本格的」「一流」等の品質断言が根拠ある表現になっているか
- [ ] 「〇〇%OFF」の比較対象（通常価格）が明示されているか

### 10. 免責文・注記チェック

- [ ] 導入文のstrong締め直後に掲載順・価格時点・キャンペーン条件の注記があるか
- [ ] まとめ末尾に価格時点・編集部基準の免責文があるか
- [ ] 疾病名を含む記事の場合、医療助言ではない旨の免責文があるか
- [ ] 比較表（複数社横並びtable）の直下に注記テンプレートがあるか

### 11. 出典URL併記チェック（v4.0 新規・§F-4）

- [ ] 具体的な数値・統計に `[出典名](URL)` 形式でリンクが併記されているか

### 12. 箇条書きチェック（v4.0 更新・§D-3）

- [ ] 選び方・メリット・注意点のH3に ulリストまたはテーブルが最低1つ入っているか（8割目安）
- [ ] ul/li内の項目末に句点（。）がないか

## 修正案の出し方

```
【品質チェック】チェック{N}
- 箇所: {H3 id} の {行}
- 問題: {何が違反しているか}
- 修正案: {具体的な修正文}
```
