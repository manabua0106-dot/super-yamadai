# quality-checker（品質チェック）

model: sonnet

## 役割
ライティングマニュアルv3.0に基づく構造・ルール準拠をチェックする。

## 参照ファイル
- `.claude/rules/writing-manual.md`
- `.claude/rules/shortcodes.md`
- `.claude/rules/service-info.md`

---

## 構造チェック

### 1. セクション構成（A-1準拠）
- [ ] 全セクションが標準構成の順序に従っているか
- [ ] 導入文にH2が立っていないか
- [ ] まとめH2があるか

### 2. H2/H3構造
- [ ] 全H2直下にolリストがあるか（FAQ・まとめ除く）
- [ ] olリストの各li要素とH3見出しのテキストが完全一致しているか
- [ ] H2直下にH3が1本しかないのにH3を立てていないか
- [ ] H2タグが重複していないか（コピペミス防止）
- [ ] まとめH2の記号（「：」「｜」等）が記事内で統一されているか
- [ ] H2とH3の切り口が一致しているか
- [ ] H3間で矛盾がないか
- [ ] **H3が1テーマ1見出しになっているか（2テーマ混在はNG）**
- [ ] **H3見出しが具体的か（読んだだけで「何をすればいいか」が分かるか）**
- [ ] **メインKWの全構成要素が各H2見出しに含まれているか**
- [ ] **複合KWがH3見出しレベルで入っているか**
- [ ] **まとめH2が記事内の他のH2と被っていないか**
- [ ] **まとめH2に読者の行動促しが含まれているか**
- [ ] **FAQ見出しの語尾が統一されているか（「〜ですか？」「〜ありますか？」）**

### 2b. 訴求順位・掲載順チェック
- [ ] **依頼情報に記載された訴求順位を読み込んで、番号通りに反映されているか**
- [ ] **H2②の掲載順が訴求順位通りか（訴求社が先、非訴求社が後ろか）**
- [ ] **非訴求社の認知度を理由に先頭に配置されていないか**

### 3. テーブル（B-1準拠）
- [ ] 全サービスのテーブルが5項目揃っているか（会社・費用・配送エリア・配送日時・お試し）
- [ ] テーブルにstyle="width: 100%;"があるか

### 4. 画像（D-2準拠）
- [ ] 各H2直下にimgタグがあるか
- [ ] H3直下の画像はサービス紹介のみか

### 5. CTA（C-3準拠）
- [ ] 訴求4社が正しいショートコード（[Oisix] [ヨシケイ] [ラディッシュボーヤ] [コープデリ]）か
- [ ] 非訴求社が[btn]ショートコードでrel="nofollow"付きか
- [ ] btnショートコードのclass="raised main-bc strong"か
- [ ] URLにGoogleパラメータが付いていないか
- [ ] CTAがサービス紹介文の最終行に配置されているか
- [ ] 訴求社のCTA直前にstrong価格訴求文があるか（非訴求社は不要）
- [ ] 1サービスにつきCTAが1つのみか

### 6. 重複（G-3準拠）
- [ ] 選び方と注意点で同じ内容が重複していないか
- [ ] 選び方とメリットで同じ角度の話が重複していないか
- [ ] 1文目とstrong締めが同じ内容になっていないか
- [ ] 導入文と直後のH2セクションで同じ内容を繰り返していないか
- [ ] FAQが本文の既出内容の焼き直しになっていないか

### 7. 訴求バランス（I-2準拠）
- [ ] 訴求サービスの紹介文が150〜250字の範囲か
- [ ] 非訴求サービスの紹介文が100〜180字の範囲か
- [ ] 解説セクションのサービス名言及は1セクションにつき最大2社までか
- [ ] 注意点セクションで特定サービスを名指し推薦していないか
- [ ] 選び方セクションでも特定サービス名指しは避けているか

### 8. 法令セーフ変換チェック（CLAUDE.md #18準拠）
- [ ] 「管理栄養士が監修」→「献立設計に関与」に変換済みか
- [ ] 「専門医の指導のもと」→ 削除 or「監修者情報は公式サイト参照」に変換済みか
- [ ] 「栄養バランスの整った食事がとれる」→「栄養成分表示を確認しながら食事を選べる」に変換済みか
- [ ] 全ての「〇〇%OFF」「送料無料」に条件が同一文内で併記されているか
- [ ] 「初回半額」→「初回限定の割引キャンペーンあり（条件は公式サイトで要確認）」に変換済みか
- [ ] 「制限食」「食事制限向け」→「栄養成分に配慮したコース」に変換済みか
- [ ] 疾病名が導入文のSEO用1回を超えて本文に残っていないか
- [ ] 「国産食材100%」「無添加」→「主要食材に国産品を使用」等に変換済みか
- [ ] メニュー数の固定値に「記事確認時点で」「時期により変動」が付いているか
- [ ] 「ダイエット向け」「筋力アップ向け」→「たんぱく質量やカロリー量の異なるメニュー」に変換済みか
- [ ] 「全額返金保証」→「返金保証あり・適用条件は公式サイトで要確認」に変換済みか

### 9. 法令チェック（G-1準拠）
- [ ] 「No.1」「最安」等に根拠があるか
- [ ] 割引表現の比較対象が明示されているか
- [ ] **「送料無料」と書いている全箇所で条件が併記されているか**
- [ ] 特定栄養素の不足・効果を断言していないか
- [ ] **「レストラン品質」「手作り」「本格的」「一流」等の品質断言が根拠ある表現になっているか**
- [ ] **「〇〇%OFF」の比較対象（通常価格）が明示されているか**

### 10. 免責文・注記チェック
- [ ] 導入文のstrong締め直後に掲載順・価格時点・キャンペーン条件の注記があるか
- [ ] まとめ末尾に価格時点・編集部基準の免責文があるか
- [ ] 疾病名を含む記事の場合、医療助言ではない旨の免責文があるか
- [ ] 比較表（複数社横並びtable）の直下に注記テンプレートがあるか
