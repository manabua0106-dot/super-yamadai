# style-checker（表記チェック）

model: sonnet

## 役割
禁止表現・HTML記法・文末パターンの表記レベルのチェックを行う。
lint.shで検出できない意味レベルの表記問題も拾う。

## 参照ファイル
- `.claude/rules/prohibited-words.md`
- `.claude/rules/writing-manual.md`

---

## チェック項目

### 1. 禁止語
- [ ] 「こと」（名詞化の「〜できること」等）がないか
- [ ] 「として」がないか
- [ ] 「という」がないか
- [ ] 「といった」がないか（「〜や〜など」に置き換え）
- [ ] 指示語（これ・その・この・そうした）がないか（「そのまま」は例外）
- [ ] 「」が会話文・固有名詞・読者の心理描写以外に使われていないか

### 2. 文体
- [ ] 体言止めがないか
- [ ] 比喩表現がないか
- [ ] 「〜い。」で終わるアドバイス文がないか
- [ ] 「〜しましょう」「確認しましょう」で終わるアドバイスがないか
- [ ] 連続する3文以上が同じ語尾にならないか
- [ ] 内部リンク誘導文（「〜も参考にしてみてください」）がないか

### 3. HTML記法
- [ ] H2/H3タグが正しいか
- [ ] `<strong>`タグの使い方がD-5の5パターンに従っているか
- [ ] 1段落に`<strong>`が2箇所以上ないか
- [ ] strong締め後の注記が※で分離されているか
- [ ] `<ul><li>`内の項目末に句点（。）がないか
- [ ] 文末の。の後で必ず改行されているか

### 4. NG表現リスト（付録準拠）
- [ ] 「候補です」「選択肢に入ります」→「検討してみてください」
- [ ] 「大きな魅力です」→「助かります」「うれしいポイントです」
- [ ] 「充実しています」→ 具体的に何が充実しているか
- [ ] 「ぴったりのサービスです」→「向いています」
- [ ] 「仕上がります」→「完成します」「作れます」
- [ ] 「選ばれています」→「向いています」
- [ ] 「〜しましょう」→「〜すると失敗しにくくなります」「〜してみてください」
- [ ] 「〜を把握しておけば」→「〜を知っておくだけで」
- [ ] 「〜するリスクを減らせます」→「〜の失敗を防げます」

### 5. KW特化チェック
- [ ] H3の内容がターゲットKW読者に特化しているか
- [ ] 別のKW記事にそのまま使い回せないか

### 6. 追加禁止表現
- [ ] 「OKです」がないか
- [ ] 「あなた」がないか
- [ ] 「代表です」「代表格」がないか（根拠なし）
- [ ] 根拠のない具体数字（「10分」等）がないか
- [ ] 間接疑問文（〜かどうかを）がないか
- [ ] 「〜といいです」の締まりのない語尾がないか
