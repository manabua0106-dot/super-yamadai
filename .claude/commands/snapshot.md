# /snapshot

数値データを正規化フォーマットで `clients/{client}/data/snapshots/YYYY-MM-DD.md` に保存する。

## 引数

- `$1`：クライアント名（省略時は確認）
- `$2`：日付（省略時は今日）

## 動作

1. 入力データのソースを判別：
   - `inbox/` にCSV/txtがある → それを読む
   - 直貼りテキスト → それをパース
   - 管理画面スクショ画像 → 文字起こしして数値抽出
2. 以下のテンプレートに正規化：

**データ取得時刻**：（例：2026-05-15 10:00）

4. 異常値があれば警告を出す（CPA急変・CV0等）

## 注意

- 元のCSV/生データは `clients/{client}/data/raw/` にもバックアップ（任意）
- 数値が一部しかない場合、空欄を「未取得」と明記し、取得タスクを提示
