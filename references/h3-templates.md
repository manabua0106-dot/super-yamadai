## 導入文テンプレート（PASONA法）

═══════════════════════════════

正本：writing-manual.md §A-2

### 構成

```
[1文目] P（Problem）: メインKWを含む悩み提起
  型例：「〇〇は、＜読者メリット＞の食材宅配サービスです。」
  型例：「〇〇で迷っていませんか？」

[2〜3文目] A（Agitation）: 放置リスクを示唆 + 「〜ですよね。」で共感
  例：「比較せずに申し込むと割高なサービスを選んでしまう可能性があります。」

[4文目] S（Solution）: 「この記事では〜を解説します」で統一

末尾: <strong>タグの行動促し文（1文のみ）
```

### 具体例：食材宅配 一人暮らし

```
食材宅配サービスは、仕事で忙しい一人暮らしの方にとって買い物の手間を減らせる便利なサービスです。

各社で料金・配送エリア・メニュー内容が大きく異なるため、比較せずに申し込むと割高なサービスを選んでしまう可能性がありますよね。

自分に合わないサービスを選ぶと、食費も時間も無駄になってしまいます。

この記事では、一人暮らしにおすすめの食材宅配サービス10選を紹介し、選び方のポイントを解説します。

<strong>まずは気になるサービスのお試しセットから試してみてください。</strong>
```

### ⚠️ 導入文ルール

- 「本記事では」ではなく「この記事では」で統一
- 「ぜひ参考にしてください」「参考になれば幸いです」等の定型文は使わない

## 選び方系 H3 のテンプレート（PREP法 + パーツ）

═══════════════════════════════

正本：writing-manual.md §E-2・§E-2補足

### 構成

```
【H3骨格】id="{id}" {選び方の見出し}
- 結論(1文目): {この選び方のポイントを1文で。KWまたは複合KWを含める}
- 根拠(2文目): {なぜこのポイントが重要か。具体的な数字や事実}
- 追加情報: {読者が実際に比較するための具体的な情報}
- パーツ: ポイントmybox(黄) → {比較すべき項目の箇条書き}
- マーカー: {本文・myboxと別角度の重要情報}
- strong締め: {具体的な確認方法 or 行動。「公式サイトで〇〇を確認すれば〜」等}
```

### 具体例：「送料込みの月額費用で比較する」

```html
<h3>送料込みの月額費用で比較する</h3>

食材宅配サービスの料金を比較するときは、商品代金だけでなく送料や年会費も含めた月額の総費用で比べるのが安全です。

送料は注文金額や配送エリアによって変わるサービスが多く、商品代金が安くても送料を加えると割高になるケースがあります。

<ul>
<li>商品代金</li>
<li>送料（注文金額・地域別）</li>
<li>年会費・入会金</li>
<li>追加オプション料金</li>
</ul>

<strong>公式サイトの料金ページで定期コースの送料条件を確認すれば、月々の食費が想定外に増えるのを防げます。</strong>
```

## メリット系 H3 のテンプレート（PREP法）

═══════════════════════════════

### 構成

```
【H3骨格】id="{id}" {メリットの見出し}
- 結論(1文目): {読者にとっての具体的な効果。KWまたは複合KWを含める}
- 根拠(2文目): {なぜその効果が得られるか}
- 追加情報: {効果の具体的な場面描写}
- パーツ: なし or ポイントmybox → {メリットの具体例}
- マーカー: {読者の生活が変わる一文}
- strong締め: {読者にとっての価値。1文目と角度を変える}
```

### 具体例：「買い物の往復時間がゼロになる」

```html
<h3>買い物の往復時間がゼロになる</h3>

食材宅配サービスを使えば、スーパーへの往復と食材選びにかかる時間を丸ごと省けます。

注文はスマホで5分ほどで完了し、指定した曜日に自宅まで届けてもらえます。

週2回の買い物に往復1時間かかっていた場合、月に約8時間の時間が浮く計算になります。

<strong>買い物にかかっていた時間を自分の休息や趣味に使えるようになります。</strong>
```

## 注意点系 H3 のテンプレート（PREP法）

═══════════════════════════════

### 構成

```
【H3骨格】id="{id}" {注意点の見出し}
- 結論(1文目): {注意すべきポイントを1文で。KWまたは複合KWを含める}
- 根拠(2文目): {なぜ注意が必要か。失敗パターン}
- 追加情報: {具体的な対策方法}
- パーツ: 注意mybox(赤) → {注意すべき項目の箇条書き}
- マーカー: {対策の具体的な行動}
- strong締め: {この対策をとると何が避けられるか}
```

### 具体例：「少量注文だと送料の負担が大きくなる」

```html
<h3>少量注文だと送料の負担が大きくなる</h3>

一人暮らしで少量しか注文しない場合、送料の割合が高くなり、実質的に割高なサービスになってしまいます。

1回の注文金額が3,000円未満だと、送料が商品代の2〜3割を占めることもあります。

<ul>
<li>1回の注文金額が3,000円未満</li>
<li>送料無料の条件が5,000円以上</li>
<li>冷凍便の追加送料がかかる</li>
</ul>

<strong>送料無料の条件を公式サイトで確認してからまとめ買いすれば、送料の負担を抑えられます。</strong>
```

## サービス紹介系 H3 のテンプレート（FAB法 + 訴求社strong価格訴求文）

═══════════════════════════════

正本：writing-manual.md §B-2

### 構成

```
【サービス紹介H3】（骨格不要・テンプレコピペ）

1. service-info.mdからテーブルHTMLをコピペ
2. テーブル直下に紹介文を書く：

段落1（Feature・特徴）: <strong>サービスの特徴を1つ</strong>
  - メインKW/複合KWを含める
  - 特徴は1つに絞る

段落2（Advantage・他社との違い）
  - 具体的に何が違うか
  - 比較対象を明示

段落3（Benefit・読者にとっての価値）
  - 機能の羅列ではなく、読者の生活・食卓での効果に変換

段落4（訴求社のみ・strong価格訴求文）
  - <strong>価格・割引情報</strong>をCTA直前に配置
  - 「〇〇%OFF」と書いた同一文内に適用条件を併記

CTA（service-info.mdからコピペ）
```

### ⚠️ v4.0 の重要ルール

- **段落4 strong価格訴求文は訴求社のみ**。非訴求社には入れない
- テックジム的な「テックジム除外」ルールではなく、**訴求順位に基づく書き分け**

### 具体例（訴求社・FAB法 + strong価格訴求文）

```html
<h3>1.Oisix（オイシックス）</h3>

<img class="size-full wp-image-XXX aligncenter" src="..." alt="" width="800" height="XXX" />

<table style="width: 100%;">
（5行テーブル・service-info.mdからコピペ）
</table>

<strong>Oisixは、有機野菜やミールキットを自宅に届けてくれる食材宅配サービスです。</strong>
[段落1: Feature]

20分以内で主菜と副菜が完成するミールキット「Kit Oisix」は、献立を考える手間も省けます。
[段落2: Advantage - 他社ミールキットとの違い]

カット済み・下味付きの食材が届くため、包丁を使う回数が少なく、洗い物も減らせます。野菜は契約農家から仕入れたものを使い、合成保存料・合成着色料は不使用です。
[段落3: Benefit - 読者の生活効果]

<strong>初回限定のおためしセットは1,980円（税込・送料無料）で届きます。</strong>
[段落4: strong価格訴求文（訴求社のみ）]

[Oisix]
```

### 具体例（非訴求社・FAB法）

```html
<h3>5.パルシステム</h3>

（テーブル省略）

<strong>パルシステムは、産直食材を中心に扱う生協の食材宅配サービスです。</strong>
[段落1: Feature]

国産の食材にこだわり、化学調味料不使用のオリジナル商品を多数取り揃えています。
[段落2: Advantage]

注文はアプリで完結し、毎週届く商品カタログから必要なものだけ選べます。
[段落3: Benefit]

[btn href="..." class="raised main-bc strong" target="_blank" rel="nofollow"]パルシステムの公式サイトはこちら[/btn]
※ 非訴求社はstrong価格訴求文を入れない
```

### 書き出しパターン（最低3種類・15社で同一5社まで）

```
パターンA: 「〇〇は、＜特徴＞の冷凍宅配弁当です。」
パターンB: 「＜特徴＞を提供する〇〇は、」
パターンC: 「〇〇の最大の特徴は、〜です。」
パターンD: 「＜特徴＞を掲げる〇〇は、」
パターンE: 「〇〇は、＜特徴＞に特化した宅配弁当です。」
```

### ⚠️ チェックポイント

- [ ] 段落1のstrong 1文目に複合KW（「宅配弁当」「食材宅配サービス」等）が含まれている
- [ ] 段落1の特徴が1つに絞られている
- [ ] 段落2で他社との違いを具体的に述べている
- [ ] 段落3で読者メリットに変換されている（機能の羅列で終わっていない）
- [ ] テーブルに記載した情報を本文で同じ角度で繰り返していない
- [ ] 書き出しパターンが同じ記事内で3種類以上ある
- [ ] **訴求社のCTA直前にstrong価格訴求文あり**
- [ ] **非訴求社のCTA直前にstrong価格訴求文なし**
- [ ] CTAがサービス紹介文の最終行に配置されている
- [ ] 1サービスにつきCTAが1つのみ

## FAQ H3 のテンプレート

═══════════════════════════════

正本：writing-manual.md §A-6

### 構成

```
<h3>Q. 質問文（「〜ですか？」「〜ありますか？」「〜ますか？」で統一）</h3>
[1文目] 回答の結論
[2〜3文目] 補足・具体的な情報
```

### ルール

- 本文で既に扱った内容の焼き直しは禁止
- サジェスト・PAA・競合のFAQから、本文で未対応のニーズを選ぶ
- 質問の語尾は「〜ですか？」「〜ありますか？」「〜ますか？」で統一
- 知恵袋への言及は入れない（writing-manual §E-7b）
- FAQ質問文に番号プレフィックス（「質問1：」「Q1：」等）を付けない

### 具体例

```html
<h3>Q. 一人暮らしでも食材宅配は元が取れますか？</h3>

食材を使い切るコツさえ押さえれば、一人暮らしでも元が取れます。

冷凍保存できる食材や、少量パックのコースを選べば食材のロスを減らせます（[Oisix公式](https://...)）。

自炊のガス・水道代や外食費を含めた総コストで比較してみてください。
```

## まとめ H2 のテンプレート

═══════════════════════════════

正本：writing-manual.md §A-5

### 構成

```
[1文目] <strong>記事全体の結論を1文で要約（メインKW含む）</strong>
[2文目] <strong>読者にとっての最も重要なポイント</strong>
[3文目] 具体的な次のアクション（お試しセット・資料請求・公式サイト確認等）
```

### ボリューム

- 3〜5文で短く締める
- 本文の繰り返しにしない

### 具体例

```html
<h2>まとめ：一人暮らし向けの食材宅配を試して食生活を快適にしよう</h2>

<strong>食材宅配サービスは各社で料金・送料・配送エリアが異なるため、一人暮らしの生活リズムに合ったサービスを選ぶのが重要です。</strong>

<strong>お試しセットを活用すれば、少ない負担で味と使い勝手を確認できます。</strong>

気になるサービスの公式サイトで郵便番号を入力し、対象エリアかどうかを先に確認してみてください。
```

### ⚠️ v4.0 の変更

- 「いかがでしたか」「参考になれば幸いです」等のAI定型で終わらない
- まとめH2の見出しが他のH2と被らない
- 読者の行動促しを見出しに含める
