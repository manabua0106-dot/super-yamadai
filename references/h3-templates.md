# H3タイプ別 骨格テンプレート

writerが骨格を書く前に該当タイプのテンプレートを参照し、正解パターンを確認してから書く。

---

## テンプレートA: 選び方系H3

```
【H3骨格】id="{id}" {選び方の見出し}
- 結論(1文目): {この選び方のポイントを1文で。KWまたは複合KWを含める}
- 根拠(2文目): {なぜこのポイントが重要か。具体的な数字や事実}
- 追加情報: {読者が実際に比較するための具体的な情報}
- パーツ: ポイントmybox(黄) → {比較すべき項目の箇条書き}
- マーカー: {本文・myboxと別角度の重要情報}
- strong締め: {具体的な確認方法 or 行動。「公式サイトで○○を確認すれば〜」等}
```

**合格例:**
- 結論: 「食材宅配サービスの送料は会社ごとに大きく異なるため、月額の総費用で比較するのが安全です。」
- strong: 「公式サイトの料金ページで定期コースの送料条件を確認すれば、想定外の出費を防げます。」
- ※ 特定サービス名指しは避ける

---

## テンプレートB: メリット系H3

```
【H3骨格】id="{id}" {メリットの見出し}
- 結論(1文目): {読者にとっての具体的な効果。KWまたは複合KWを含める}
- 根拠(2文目): {なぜその効果が得られるか}
- 追加情報: {効果の具体的な場面描写}
- パーツ: なし or ポイントmybox → {メリットの具体例}
- マーカー: {読者の生活が変わる一文。本文とは別の角度}
- strong締め: {読者にとっての価値。1文目と角度を変える}
```

**合格例:**
- 結論: 「食材宅配サービスを使えば、スーパーへの往復と食材選びにかかる時間を丸ごと省けます。」
- strong: 「買い物にかかっていた時間を自分の休息や趣味に使えるようになります。」

---

## テンプレートC: 注意点系H3

```
【H3骨格】id="{id}" {注意点の見出し}
- 結論(1文目): {注意すべきポイントを1文で。KWまたは複合KWを含める}
- 根拠(2文目): {なぜ注意が必要か。失敗パターン}
- 追加情報: {具体的な対策方法}
- パーツ: 注意mybox(赤) → {注意すべき項目の箇条書き}
- マーカー: {対策の具体的な行動}
- strong締め: {この対策をとると何が避けられるか}
```

---

## テンプレートD: サービス紹介系H3（骨格不要・テンプレコピペ）

サービス紹介H3は骨格を書かない。以下の手順でテンプレートコピペ+紹介文追記。

```
手順:
1. service-info.mdから該当サービスのテーブルHTMLをコピペ
2. テーブル直下に紹介文3〜5段落を書く
3. 訴求社: 段落4にstrong価格訴求文 → CTA
4. 非訴求社: 段落3〜4で終了 → [btn]CTA
```

---

## テンプレートE: FAQ系H3（骨格不要）

```
<h3>{質問文}</h3>
{回答文2〜3文}
```

- 質問文に番号プレフィックス（「質問1：」等）を付けない
- 本文で扱っていないユーザーニーズに限定
- 本文の焼き直し禁止
