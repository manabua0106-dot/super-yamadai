# H3タイプ別 骨格テンプレート

writerが骨格を書く前に該当タイプのテンプレートを参照し、正解パターンを確認してから書く。

---

## テンプレートA: 選び方系H3

```
【H3骨格】id="{id}" {選び方の見出し}
- 結論(1文目): {読者がすべき行動を1文で。「〜してみてください」「〜すると〜を避けられます」の型。KWまたは複合KWを含める}
- 根拠(2文目): {なぜこのポイントが重要か。具体的な数字や事実}
- 追加情報: {読者が実際に比較するための具体的な情報}
- パーツ: ul → {チェックすべき項目の箇条書き。li末尾に句点なし}
- strong締め: {1文目と角度を変える。1文目が行動→strongはメリット/結果。1文目が結論→strongは具体的行動}
```

**合格例（完成版記事から）:**
```
1文目: 「宅食を選ぶときは、公式サイトで1食あたりのカロリー・糖質・たんぱく質・脂質の数値をチェックしてみてください。」（行動提案型）
strong: 「自分の食事スタイルに合ったコースを見つけやすくなります。」（メリット型）

1文目: 「注文前に公式サイトで対象エリアと受け取り方法を調べておくと、「届かなかった」というトラブルを避けられます。」（結論型）
strong: 「公式サイトの配送情報ページで対象エリアと日時指定の可否を調べておくと安心です。」（安心の提示型）
```

- ※ 特定サービス名指しは避ける
- ※ 1文目は30文字以内目安。50文字超は分割
- ※ ul使用率は全H3の50%以上が目安

## テンプレートB: メリット系H3

```
【H3骨格】id="{id}" {メリットの見出し}
- 結論(1文目): {「ダイエット中の宅食なら〜」「ダイエット中に宅食を利用すると〜」でKWを含め、読者にとっての具体的な効果を述べる}
- 対比(2文目): {「外食やコンビニ弁当では〜」「自炊で〜しようとすると〜」で現状の問題を1文}
- 解決(3文目): {「宅食なら〜」で宅食の優位性に戻る}
- strong締め: {読者の生活がどう変わるか。1文目=何ができるか、strong=生活への影響で角度を変える}
```

**合格例（完成版記事から）:**
```
1文目: 「ダイエット中の宅食なら、自分で栄養計算をしなくても1食あたりのカロリーを数値で確かめられます。」（不要な行為の免除）
strong: 「宅食なら数値を見るだけで1日の摂取カロリーを計算できます。」（具体的行動）

1文目: 「ダイエット中に宅食を利用すると、1食分のおかずが容器に盛り付けられた状態で届くので、食べすぎの心配がなくなります。」（不安の解消）
strong: 「容器1つ分の量だけ食べればカロリーオーバーにならないため、食事量を意識しなくていいのがメリットです。」（読者メリット）
```

## テンプレートC: 注意点系H3

```
【H3骨格】id="{id}" {注意点の見出し}
- 結論(1文目): {注意すべきポイントを1文で。KWまたは複合KWを含める。4パターンから選択:}
  - 打ち消し型: 「〜わけではありません。」
  - リスク提示型: 「〜しても、〜場合があります。」
  - 注意喚起型: 「〜は押さえておいてください。」
  - 失敗パターン型: 「〜多い失敗パターンのひとつは〜です。」
- 根拠(2文目): {なぜ注意が必要か。失敗パターンの具体例}
- 対策(3〜4文目): {具体的な対策方法。「〜してみてください」で行動提案}
- strong締め: {具体的な行動 or この行動をとると何が変わるか}
```

**合格例（完成版記事から）:**
```
1文目: 「宅食を食べるだけで体重が減るわけではありません。」（打ち消し型）
対策: 「ウォーキングや階段の利用など、生活の中に取り入れやすい運動を組み合わせてみてください。」
strong: 「宅食だけに頼らず、軽い運動と組み合わせると健康的な食生活を維持しやすくなります。」

1文目: 「ダイエット中の宅食で多い失敗パターンのひとつは「味が合わなかった」です。」（失敗パターン型）
対策: 「口コミやSNSで味の評判を事前に調べておくと、サービス選びの参考になります。」
strong: 「いきなり定期コースに申し込まず、まず1回分の注文で味とボリュームを確かめてみてください。」
```

- ※ 見出しに「対策」「解決策」は入れない。対策は本文内で自然に触れる
- ※ 注意点H3にもKW「ダイエット」を1文目に含める

## テンプレートD: サービス紹介系H3（骨格不要・テンプレコピペ）

サービス紹介H3は骨格を書かない。以下の手順でテンプレートコピペ+紹介文追記。

```
手順:
1. service-info.mdから該当サービスの画像HTML・テーブルHTMLをコピペ
2. H3タグにid属性を付与（例: <h3 id="1a">）
3. テーブル直下に紹介文を書く
   - 訴求社: 3〜5段落（150〜250字）
   - 非訴求社: 2〜3段落（100〜180字）
4. 訴求社: 段落4にstrong価格訴求文 → CTA
5. 非訴求社: 最終段落のあと → [btn]CTA（strong価格訴求文なし）

書き出しパターン（最低3種を分散して使う）:
A: 「○○は、〜の冷凍宅配弁当です。」（最大4社）
B: 「〜を特徴とする○○は、〜」（最大4社）
C: 「○○の最大の特徴は〜です。」（最大4社）

チェックポイント:
- テーブルと本文で同じ数字・同じ角度を繰り返さない（FL-22）
- 「電子レンジで温めるだけ」は記事全体で2社まで（FL-24）
- 全紹介文にKW「ダイエット」「宅食」を各1回含める（FL-29）
- 割引表記には必ず比較対象を同一文内に明記（FL-1）
```

## テンプレートE: FAQ系H3（骨格不要）

```
<h3>{質問文（ですか？/ますか？で統一）}</h3>

{1文目: 質問への直接回答（結論から）}
{2〜3文目: 補足情報 or 注意事項}
{最終文: 行動提案（「〜してみてください」「〜してから始めてください」）}
```

- 質問文に番号プレフィックス（「質問1：」等）を付けない
- 本文で扱っていないユーザーニーズに限定
- 本文の焼き直し禁止
- strong締めなし（FAQにはstrongを使わない）
- 回答は3〜4文
- 2社比較型のFAQ（ワタミ vs nosh等）は4文（A特徴→A注意→B特徴→行動提案）

---

## テンプレートF: まとめ（3文構成）

```
<h2>まとめ：{H2見出し}</h2>

<strong>{記事全体の要約。導入文1文目とは角度を変える。「〜は、〜で〜を〜できる方法です。」}</strong>

{選び方の要約 or 行動促し。「サービスを選ぶときは、〜の○つを基準に比較してみてください。」}

<strong>{行動促し。「気になるサービスの公式サイトをチェックして、〜してみましょう。」}</strong>

※（免責文3行: 価格時点+変動注記 / おすすめの定義 / 妊娠中・授乳中・治療中の相談先）
```
