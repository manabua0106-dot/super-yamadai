## v5の骨格の考え方（情報インベントリ方式）

**スロットを埋めるのではなく、持っている情報を棚卸しする。**

1. 先に「伝える事実」を列挙する（数字・固有名詞・条件で書けるものだけ）
2. 各事実を「文／ul／table」のどれで出すか宣言する（パーツ設計）
3. 文数は事実の数で決まる。**事実が2つなら2〜3文でよい**（上限目安4〜6文・下限なし）
4. 言い換え・当たり前の総括・「〜が魅力です」等の埋め文は書かない（§E-12）

### パーツ設計の判断基準

| 情報の形 | 使うパーツ |
|---|---|
| 3項目以上の列挙（確認項目・対処法・選択肢） | ul（直前に誘導1文） |
| 対になる比較（向き/不向き・コース×価格・冷蔵/冷凍） | table（2列以上） |
| 数値が2軸以上（サービス×料金×送料） | table |
| 事実1つ＋理由 | 文（PREP） |

※ 表・ulで出した数字・項目を本文で言い直さない（§G-4）。

## 導入文テンプレート（PASONA法・骨格不要）

═══════════════════════════════

正本：writing-manual.md §A-2

```
[1文目] P（Problem）: メインKWを含む悩み提起
[2〜3文目] A（Agitation）: 放置リスクを示唆 + 「〜ですよね。」で共感
[4文目] S（Solution）: 「この記事では〜を解説します」で統一
末尾: <strong>タグの行動促し文（1文のみ）
```

### 具体例：食材宅配 一人暮らし

```
食材宅配サービスは、仕事で忙しい一人暮らしの方が買い物の時間を減らせるサービスです。

各社で料金・配送エリア・メニュー内容が大きく異なるため、比較せずに申し込むと割高なサービスを選んでしまいますよね。

自分に合わないサービスを選ぶと、食費も時間も無駄になってしまいます。

この記事では、一人暮らしにおすすめの食材宅配サービス10選を紹介し、選び方のポイントを解説します。

<strong>まずは気になるサービスのお試しセットから試してみてください。</strong>
```

- 「本記事では」ではなく「この記事では」で統一
- 「ぜひ参考にしてください」等の定型文は使わない

## 選び方系 H3 のテンプレート（PREP法 + パーツ設計）

═══════════════════════════════

正本：writing-manual.md §E-2・§E-2補足

### 骨格の型

```
【H3骨格】id="{id}" {選び方の見出し}
■ 伝える事実
  1. {比較・確認の判断基準（何をどう比べるか）}
  2. {なぜその基準か（失敗パターン・数字）}
  3. {確認する具体的な項目や手順（あれば）}
■ パーツ設計
  - 事実1・2 → 文
  - 事実3 → ul（確認項目が3つ以上あるとき）
■ 結論(1文目): {判断基準を1文で。KWまたは複合KWを自然に}
■ strong締め: {任意。具体的な確認方法・行動が書ける場合のみ}
■ 共起語: {このH3で入れる共起語}
```

### 文章化の例：「送料込みの月額費用で比較する」

```html
<h3>送料込みの月額費用で比較する</h3>

食材宅配サービスの料金は、商品代金に送料や年会費を足した月額の総費用で比べてください。

送料は注文金額や配送エリアで変わるサービスが多く、商品代金が安くても総額では割高になるケースがあるからです。

比べるときに確認する費用は次の通りです。

<ul>
<li>商品代金</li>
<li>送料(注文金額・地域別)</li>
<li>年会費・入会金</li>
</ul>

<strong>公式サイトの料金ページで定期コースの送料条件まで確認すると、月額の総費用で比較できます。</strong>
```

**ポイント**：1文目が結論／2文目が理由（「〜からです」で接続）／列挙はulへ／strongは具体的な行動。ulの項目を本文で言い直していない。

## メリット系 H3 のテンプレート（PREP法）

═══════════════════════════════

### 骨格の型

```
【H3骨格】id="{id}" {メリットの見出し}
■ 伝える事実
  1. {読者の生活で何がどう変わるか（具体的な場面・数字）}
  2. {なぜそうなるか（サービスの仕組み）}
■ パーツ設計
  - 原則は文。効果が複数の場面に及ぶときだけul
■ 結論(1文目): {効果を具体的に。KWまたは複合KWを自然に}
■ strong締め: {任意。読者の生活変化 or 数字で裏付けられる価値}
■ 共起語: {このH3で入れる共起語}
```

### 文章化の例：「買い物の往復時間がなくなる」

```html
<h3>買い物の往復時間がなくなる</h3>

食材宅配サービスを使えば、スーパーへの往復と食材選びにかかる時間をまるごと省けます。

注文はスマホで5分ほどで完了し、指定した曜日に自宅まで届けてもらえます。

週2回の買い物に往復1時間かかっていた場合、月に約8時間が浮く計算です。

<strong>買い物にかかっていた時間を、家族と過ごす時間や自分の趣味に使えるようになります。</strong>
```

**ポイント**：3文＋strongで完結。効果を「月に約8時間」と数字にしている。同じ効果を言い換えた4文目を足さない。

## 注意点系 H3 のテンプレート（PREP法 + パーツ設計）

═══════════════════════════════

### 骨格の型

```
【H3骨格】id="{id}" {注意点の見出し}
■ 伝える事実
  1. {何が起きるか（失敗パターン・条件・数字）}
  2. {どう対処するか（具体的な行動）}
■ パーツ設計
  - 対処法・確認項目が3つ以上 → ul
  - 「向く人/向かない人」等の対の情報 → table
■ 結論(1文目): {注意点を1文で。KWまたは複合KWを自然に}
■ strong締め: {任意。対処の具体的な行動}
■ 共起語: {このH3で入れる共起語}
```

### 文章化の例：「少量注文だと送料の負担が大きくなる」

```html
<h3>少量注文だと送料の負担が大きくなる</h3>

一人暮らしで少量だけ注文すると、送料の割合が高くなり1食あたりの金額が上がります。

1回の注文が3,000円未満の場合、送料が商品代の2〜3割を占めるサービスもあるからです。

送料をおさえる方法は次の通りです。

<ul>
<li>送料無料になる注文金額までまとめ買いする</li>
<li>冷凍品を中心に選んで配送回数を減らす</li>
<li>自社便エリアのサービスを選ぶ</li>
</ul>

<strong>注文前に送料無料の条件を公式サイトで確認し、条件を超える単位でまとめ買いすると送料の負担をおさえられます。</strong>
```

## 口コミ解説 H3 のテンプレート（口コミ・評判記事用・v5新設）

═══════════════════════════════

正本：writing-manual.md §A-7

### 骨格の型

```
【H3骨格】id="{id}" {口コミの見出し（例：量が少なめで物足りないとの声）}
■ 引用する口コミ: {実在口コミのURL・出典（原文ママ・改変禁止）}
■ 伝える事実（⚠️ 口コミの言い換えは事実に数えない。新しい情報だけ）
  1. {なぜそうなるか（原因・仕組み・数字）}
  2. {どうすればよいか（対処・選び方・具体的なコース名等）}
■ パーツ設計
  - 対処法が2つ以上 → ul
  - 「合う人/合わない人」 → table
■ 導入1文: {何についての口コミかを示す}
■ strong締め: {任意。対処・数字を含む文に付けられる場合のみ}
```

### 文章化の例：「量が物足りないとの声」

```html
<h3>たくさん食べる人には量が物足りない</h3>

量については、味は良くても物足りなさを感じたという口コミがあります。

<blockquote>（実在口コミの原文ママ）
<cite>— 投稿者（@handle）YYYY年M月D日のXより
出典確認元：<a href="URL" target="_blank" rel="nofollow noopener">X</a></cite></blockquote>

お弁当はカロリーと塩分を計算して作られているため、よく食べる方や若い男性には少なく感じる場合があります。

量が足りないときの調整方法は次の通りです。

<ul>
<li>ご飯や汁物を自分で足す</li>
<li>おかず5品の「いつでも五菜」を選ぶ</li>
<li>単品メニューを組み合わせる</li>
</ul>
```

**ポイント**：解説は「原因1文＋対処ul」だけで完結。
**書いてはいけない文**：「物足りないと感じる方もいます」（口コミの言い換え）／「この口コミのように〜する方もいます」（blockquoteの再説明）／「食べ応えを重視する方は工夫が必要です」（対処ulの言い換え総括）。

## サービス紹介系 H3 のテンプレート（FAB法 + 訴求社strong価格訴求文）

═══════════════════════════════

正本：writing-manual.md §B-2・§C-1補足2

### 構成

```
【サービス紹介H3】（骨格不要・テンプレコピペ）

1. _table登録済みサービス → [サービス名_table] をH3直下に1行（画像＋テーブル直書き禁止）
   未登録サービスのみ → service-info.md から画像＋テーブルHTMLをコピペ
2. 紹介文（本文2〜4文・strong含めて4〜6文）：

段落1（Feature・特徴）: <strong>特徴を1つ（複合KW含む）</strong>
  - 「〇〇は、〜です。」のシンプルな主語＋述語
段落2（Advantage・他社との違い）: 具体的に何が違うか
段落3（Benefit・読者にとっての価値）: 生活・食卓での効果に変換
段落4（訴求社のみ・任意）: <strong>具体的な価格・割引があるときのみ価格訴求文</strong>
  - 「〇〇%OFF」と書いた同一文内に適用条件を併記
  - 情報の薄い決まり文句（「割引価格で用意されています」等）は置かない

CTA（service-info.mdからコピペ・最終行に1つ）
```

### 具体例（訴求社・_table登録済み）

```html
<h3 id="1a">Oisix（オイシックス）</h3>

[Oisix_table]

<strong>Oisixは、20分以内で主菜と副菜が完成するミールキットを届けてくれる食材宅配サービスです。</strong>

カット済み・下味付きの食材とレシピがセットで届くため、献立を考える手間がありません。

包丁を使う回数が少なく、調理後の洗い物も減らせます。

<strong>初回限定のおためしセットは、Kit Oisixを含む複数品が特別価格（税込・送料無料）で試せます。</strong>

[Oisix]
```

### 具体例（非訴求社・_table未登録）

```html
<h3 id="8a">nosh（ナッシュ）</h3>

（service-info.md のテーブル・画像をコピペ）

<strong>noshは、メニューを1食ずつ自分で選べる冷凍宅配弁当です。</strong>

全メニューが糖質・塩分に配慮した基準で作られており、新メニューが定期的に追加されます。

食べたいものだけ選べるため、苦手なおかずが届く失敗を避けやすいです。

[btn href="https://nosh.jp/" class="raised main-bc strong" target="_blank" rel="nofollow"]noshの公式サイトはこちら[/btn]
```

### チェックポイント

- [ ] 段落1のstrong 1文目に複合KW（「宅配弁当」「食材宅配サービス」等）が含まれている
- [ ] 段落1の特徴が1つに絞られている
- [ ] テーブルに記載した情報を本文で同じ角度で繰り返していない
- [ ] 書き出しパターンが同じ記事内で3種類以上ある（15社なら同一パターン最大5社）
- [ ] 訴求社の段落4は具体的な価格・割引があるときのみ／非訴求社にはなし
- [ ] 利用シミュレーション文（「夫婦で1日1食ずつなら〜」等）を書いていない
- [ ] CTAが最終行に1つだけ

### 書き出しパターン（最低3種類）

```
パターンA: 「〇〇は、＜特徴＞の冷凍宅配弁当です。」
パターンB: 「＜特徴＞を提供する〇〇は、」
パターンC: 「〇〇は、＜特徴＞を届けてくれる食材宅配サービスです。」
パターンD: 「〇〇は、＜特徴＞に特化した宅配弁当です。」
```

## FAQ H3 のテンプレート

═══════════════════════════════

正本：writing-manual.md §A-6

### 構成

```
<h3>質問文（「〜ですか？」「〜ありますか？」「〜ますか？」で統一）</h3>
[1文目] 回答の結論
[2〜3文目] 補足・具体的な情報（2〜3文で完結）
```

### ルール

- 本文で既に扱った内容の焼き直しは禁止
- サジェスト・PAA・競合のFAQから、本文で未対応のニーズを選ぶ
- 知恵袋への言及は入れない（writing-manual §E-7b）
- 質問文に番号プレフィックス（「Q1：」等）を付けない
- FAQのH2直下に質問一覧のolを置かない

### 具体例

```html
<h3>一人暮らしでも食材宅配は元が取れますか？</h3>

食材を使い切れれば、一人暮らしでも元が取れます。

冷凍保存できる食材や少量パックのコースを選ぶと、食材を余らせずに使えます。

自炊の光熱費や外食費を含めた総額で比べてみてください。
```

## まとめ H2 のテンプレート

═══════════════════════════════

正本：writing-manual.md §A-5

### 構成

```
[1文目] <strong>記事全体の結論を1文で要約（メインKW含む）</strong>
[2文目] 補足（読者の判断基準）
[3文目] <strong>具体的な次のアクション</strong>
```

- 3〜5文で短く締める。本文の繰り返しにしない
- 「いかがでしたか」等のAI定型で終わらない
- まとめH2の見出しは他のH2と被らせず、行動促しを含める

### 具体例

```html
<h2>まとめ：一人暮らしの食材宅配は送料込みの総額で選ぼう</h2>

<strong>一人暮らし向けの食材宅配は、少量注文のしやすさと送料込みの月額で選ぶと失敗しにくいです。</strong>

受け取りやすさは置き配や日時指定の対応で変わるため、生活リズムに合うかも確認してみてください。

<strong>まずは気になるサービスのお試しセットを1つ注文し、味と量を確かめてから定期利用を判断してください。</strong>
```
