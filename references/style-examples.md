# 本文の装飾・文体パターン例

## 導入文の正解パターン（5要素＋免責文）

```
1文目（読者メリット型）: 「〜に〜を取り入れると、〜できます。」
  ※「〜は〜です」の定義文は禁止。読者メリットから始める
2文目（共感文）: 「〜と感じている方も多いのではないでしょうか。」
  ※「」で読者の心理描写。「ですよね」より「のではないでしょうか」が◎
3文目（記事予告）: 「この記事では、〜を〜で比較しています。」
4文目（補足予告）: 「〜も解説していますので、〜にしてみてください。」
5文目（strong行動促し）: 「自分に合った〜を見つけて、〜してみてください。」

免責文ブロック（strong直後に※4行）:
※掲載順はランキングではありません。料金は〇年〇月時点の各公式サイト掲載情報をもとに算出しています。
※価格・送料・割引・特典は商品、地域、会員条件、注文金額、実施時期により異なります。
※キャンペーン・送料無料・返金保証・値引き特典の適用条件は各公式サイトで必ずご確認ください。
※（記事テーマ別の免責。ダイエット記事なら「減量効果や疾病の改善を保証するものではありません」）
```

## H2導入文の正解パターン

### リスク提示型（選び方・サービス紹介・注意点で使用）
```
1文目（現状認識）: 「〜は各社で〜が大きく異なります。」
2文目（リスク）: 「比較せずに申し込むと、〜してしまう可能性があります。」
3文目（橋渡し）: 「以下の○つの基準で比較すると、失敗しにくくなります。」
※olリストの具体的な内容には踏み込まない（FL-23）
```

### メリット提示型（メリットで使用）
```
1文目（メリット概要）: 「〜に切り替えると、〜だけでなく複数のメリットがあります。」
2文目（橋渡し）: 「〜の方は、以下の○点を判断材料にしてみてください。」
※olリストの4項目の内容を先出ししない
```

### FAQ・まとめ
- FAQ: 1文のみ「ここでは、〜に関するよくある質問に回答します。」（olリストなし）
- まとめ: 導入文なし。直接strong文から開始

## サービス紹介文の合格パターン

### 訴求社の例（Dr.つるかめキッチン）

```html
<h3 id="1a">1.Dr.つるかめキッチン</h3>

<img class="size-full wp-image-302 aligncenter" src="https://www.super-yamadai.co.jp/article/wp-content/uploads/2026/03/tsurukame-kitchen-1.jpg" alt="" width="800" height="401" />

<table style="width: 100%;">（5行テーブル）</table>

<strong>Dr.つるかめキッチンは、カロリーや糖質に配慮した5種類のコースから選べる冷凍宅配弁当です。</strong>

管理栄養士が献立設計に関与しており、1食あたりのカロリー・塩分・糖質の数値がコースごとに明示されています。
ダイエット中の宅食でコースを迷っている方でも、栄養成分の数値を見るだけで自分に合ったメニューを絞り込めます。

電子レンジで温めるだけで主菜と副菜がそろった食事が用意できます。

<strong>定期コースは都度購入価格から28%OFF・送料無料で、カロリー制限気づかい御膳は1食あたり約730円（税込）から注文できます（適用条件は公式サイトをご確認ください）。</strong>

[Dr.ツルガメキッチン]
```

### 非訴求社の例（nosh）

```html
<h3 id="6a">6.nosh（ナッシュ）</h3>

（テーブル省略）

<strong>noshは、全メニュー糖質に配慮して設計された冷凍宅配弁当です。</strong>

和食・洋食・中華・デザートまで幅広いジャンルがそろっています。
毎回自分で好きなメニューを指定できるため、ダイエット中の宅食で同じ料理が続く心配がありません。

解約金がかからないため、合わなければすぐにやめられます。

[btn href="https://nosh.jp/" class="raised main-bc strong" target="_blank" rel="nofollow"]noshの公式サイトはこちら[/btn]
```

### 合格ポイント
- 訴求社: テーブル → 紹介文 → strong価格訴求文 → CTA
- 非訴求社: テーブル → 紹介文 → [btn]CTA（strong価格訴求文なし）
- 段落1（strong）は特徴1つに絞る
- テーブルと本文で同じ角度の繰り返しを避ける
- 書き出しパターンは最低3種（FL-4）
- 全紹介文にKW「ダイエット」「宅食」を各1回含める（FL-29）
- 非訴求社は100〜180字、訴求社は150〜250字（FL-14）

## 選び方H3の合格パターン

```html
<h3>外食やコンビニとの食費差で選ぶ</h3>

宅食の費用を比べるときは、送料込みの月額総額で計算しましょう。

宅食の費用は1食600〜1,000円前後が目安で、外食やコンビニ弁当と比較すると同程度かやや高めです。

定期コースで送料が無料になるサービスもあります。

1か月分の食数に単価をかけ、送料を足した月額総額で比較してみてください。

<strong>1食あたりの価格に送料を加えた月額総額で比較すると、月にいくらかかるかが分かります。</strong>
```

### 合格ポイント
- 1文目は結論（行動提案 or 注意喚起）
- 1文目にKWまたは複合KWを含める
- 特定サービス名指しは避ける
- strong締めは1文目と角度を変える（1文目=行動 → strong=結果/メリット）

## メリットH3の合格パターン

```html
<h3>1食分の量が決まっていて食べすぎを防げる</h3>

ダイエット中に宅食を利用すると、1食分のおかずが容器に盛り付けられた状態で届くので、食べすぎの心配がなくなります。

自炊や外食では「もう少し食べたい」と追加してしまいがちですが、宅食なら容器の中身が1食分の上限です。

<strong>容器1つ分の量だけ食べればカロリーオーバーにならないため、食事量を意識しなくていいのがメリットです。</strong>
```

### 合格ポイント
- 1文目は「ダイエット中の宅食なら〜」でKWを含める
- 2文目で外食・コンビニ・自炊との対比を1文入れる
- strong締めは1文目と角度を変える（1文目=何ができるか、strong=読者の生活がどう変わるか）

## 注意点H3の合格パターン

```html
<h3>味が合わないサービスだと継続できない</h3>

ダイエット中の宅食で多い失敗パターンのひとつは「味が合わなかった」です。

カロリーや価格だけを重視して選ぶと、味が好みに合わず結局やめてしまうケースが珍しくありません。

口コミやSNSで味の評判を事前に調べておくと、サービス選びの参考になります。

初回セットやお試し価格があるサービスなら、少ない出費で味を確かめてから本契約に進めます。

<strong>いきなり定期コースに申し込まず、まず1回分の注文で味とボリュームを確かめてみてください。</strong>
```

### 合格ポイント
- 1文目は注意点の結論（打ち消し or リスク or 失敗パターン）
- 対策は本文内で自然に触れる（見出しに「対策」と書かない）
- strong締めは具体的な行動

## FAQ回答の合格パターン

```html
<h3>ワタミやnoshはダイエットに向いていますか？</h3>

ワタミの宅食ダイレクトはカロリーや塩分に配慮したコースがあり、1食360円〜と価格が抑えめです。
ただし薄味に感じる利用者もいるため、味の好みは公式サイトのメニュー一覧や口コミで事前にチェックしてみてください。

noshは全メニュー糖質に配慮した設計で、和洋中を含むメニュー数の多さが特徴です。
味の評価は個人差が大きいため、どちらも初回セットやクーポンで実際に食べてから判断するのが確実です。
```

### 合格ポイント
- 1文目で質問に直接回答（結論から）
- 最終文は行動提案（「〜してみてください」「〜してから始めてください」）
- strong締めなし（FAQにはstrongを使わない）
- 本文で述べた内容の焼き直しなし

## まとめの合格パターン（3文構成）

```html
<h2>まとめ：ダイエット向け宅食おすすめ12選と選び方</h2>

<strong>ダイエット向けの宅食は、カロリーや糖質に配慮した冷凍宅配弁当で毎日の食事の手間とカロリー計算をまとめて減らせる方法です。</strong>

サービスを選ぶときは、栄養成分の数値・送料込みの月額費用・味の傾向の3つを基準に比較してみてください。

<strong>気になるサービスの公式サイトをチェックして、自分の生活スタイルに合った宅食を始めてみましょう。</strong>

※（免責文3行）
```

### 合格ポイント
- strong1文目: 記事全体の要約（導入文1文目とは角度を変える）
- 本文1文: 選び方の要約 or 行動促し
- strong2文目: 行動促し
- 導入文とまとめで同じ表現を使わない

## strong締めのNG/OK比較

| NG | 理由 | OK |
|----|------|-----|
| 美味しさだけでなく健康面でも安心できるのが大きな魅力です。 | 感想止まり | 管理栄養士が献立設計に関与したメニューなら栄養成分を自分で考える手間が省けます。 |
| 生活にゆとりが生まれます。 | 抽象的 | 買い物にかかっていた時間を自分の休息や趣味に使えるようになります。 |
| おすすめです。 | 行動不明 | お試しセットで味と量を確認してから定期コースに申し込むと失敗しにくくなります。 |
| 予算オーバーを防げます。 | AI定型「防げます」NG | 月にいくらかかるかが分かります。 |
| 食事管理の効率が高まります。 | 抽象的 | 忙しい日が続いてもカロリーを気にした食事を続けられます。 |

## 文体ルール

### 語尾の分散
- 3文連続で同じ語尾（ます。ます。ます。）にしない
- 「〜でしょうか」は導入文の共感文1回のみ
- 「〜しましょう」は記事全体で1回まで

### 文長
- 本文: 30文字目安、50文字以内
- strong価格訴求文: 50文字超OK（価格情報の正確な記載が必要なため）
- 80文字超: 禁止

### 段落
- 1文1段落が原則。文末の「。」の後は必ず改行
- 2文を1段落にまとめない
- ul/li内は例外
