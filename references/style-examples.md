## サービス紹介文の合格パターン（FAB法）

⚠️ **v4.1で「段落4 strong価格訴求文」の必須化を撤廃。** 価格情報をどの段落で扱うかは writer の判断に委ねる。

### 訴求社の例（Oisix）

```html
<h3 id="service1">1.Oisix（オイシックス）</h3>

<img class="size-full wp-image-XXX aligncenter" src="https://www.super-yamadai.co.jp/article/wp-content/uploads/YYYY/MM/oisix.jpg" alt="" width="800" height="XXX" />

<table style="width: 100%;">
（5行テーブル）
</table>

<strong>Oisixは、有機野菜やミールキットを自宅に届けてくれる食材宅配サービスです。</strong>

20分以内で主菜と副菜が完成するミールキット「Kit Oisix」は、献立を考える手間も省けます。

カット済み・下味付きの食材が届くため、包丁を使う回数が少なく、洗い物も減らせます。

野菜は契約農家から仕入れたものを使い、合成保存料・合成着色料は不使用です。初回限定のおためしセットは1,980円（税込・送料無料）で届きます。

[Oisix]
```

### 非訴求社の例（パルシステム）

```html
<h3 id="service5">5.パルシステム</h3>

（テーブル省略）

<strong>パルシステムは、産直食材を中心に扱う生協の食材宅配サービスです。</strong>

国産の食材にこだわり、化学調味料不使用のオリジナル商品を多数取り揃えています。

注文はアプリで完結し、毎週届く商品カタログから必要なものだけ選べます。

[btn href="https://www.pal-system.co.jp/" class="raised main-bc strong" target="_blank" rel="nofollow"]パルシステムの公式サイトはこちら[/btn]
```

### 合格ポイント

- H3に `id="service{N}"` を必ず付与（v4.1：必須）
- 段落1は特徴1つに絞る（strongで太字化）
- 訴求社・非訴求社ともに 100字以上（v4.1：上限撤廃）
- テーブルと本文で同じ角度の繰り返しを避ける
- 価格訴求は自然な流れで触れる（strong必須ではない）
- 一文一改行
- 書き出しは型に縛られず、わかりやすさ優先で書く

## 比較テーブル（導入文直後・v4.1で必須化）

```html
<table>
<thead>
<tr><th>サービス名</th><th>1食あたり</th><th>送料・エリア</th><th>お試し</th><th>詳細</th></tr>
</thead>
<tbody>
<tr>
  <td><a href="#service1">Oisix</a></td>
  <td>約850円〜</td>
  <td>全国（条件で送料無料）</td>
  <td>1,980円（送料無料）</td>
  <td><a href="#service1">詳細を見る</a></td>
</tr>
<tr>
  <td><a href="#service2">ヨシケイ</a></td>
  <td>約393円〜</td>
  <td>47都道府県（自社配送）</td>
  <td>シンプルミール半額</td>
  <td><a href="#service2">詳細を見る</a></td>
</tr>
<!-- 全社分続く -->
</tbody>
</table>
```

### 合格ポイント

- 導入文の strong行動促し直後に配置
- H2は立てない
- サービス名・「詳細を見る」両方を `<a href="#service{N}">` でジャンプリンク化
- 必須カラム5項目（サービス名・1食あたり単価・送料/エリア・お試し・詳細）

## 選び方H3の合格パターン

```html
<h3>送料込みの月額費用で比較する</h3>

食材宅配サービスの料金を比較するときは、商品代金だけでなく送料や年会費も含めた月額の総費用で比べるのが安全です。

送料は注文金額や配送エリアによって変わるサービスが多く、商品代金が安くても送料を加えると割高になるケースがあります。

<ul>
<li>商品代金</li>
<li>送料（注文金額・地域別）</li>
<li>年会費・入会金</li>
<li>追加オプション料金</li>
</ul>

公式サイトの料金ページで送料条件を確認すれば、月々の食費が想定外に増えるのを防げます。
```

**合格ポイント**：
- 1文目が結論から始まっている（PREP法）
- 2文目で具体的な根拠
- 箇条書きで比較項目を列挙
- 締めで具体的な行動を提示（strong必須ではない・v4.1）
- 1文目と締めが内容重複していない

## strong締めのNG/OK比較（strong使用時のみ参考）

⚠️ **v4.1：strong締め自体が必須ではない。** 自然な流れで書ける場合のみ使う。型にはめると不自然になる。

| NG | 理由 | OK |
|---|---|---|
| 美味しさだけでなく健康面でも安心できるのが大きな魅力です。 | 感想止まり | 管理栄養士が献立設計に関与したメニューなら栄養バランスを自分で考える手間が省けます。 |
| 生活にゆとりが生まれます。 | 抽象的 | 買い物にかかっていた時間を自分の休息や趣味に使えるようになります。 |
| おすすめです。 | 行動不明 | お試しセットで味と量を確認してから定期コースに申し込むと失敗しにくくなります。 |
| 〜という事態を防げます。 | 型にはめた不自然な文（v4.1で要注意） | 自然な流れで書けない場合はstrong締めを使わない |
| 〜を避けられます。 | 同上 | 同上 |

## 導入文の合格パターン（PASONA法）

```
食材宅配サービスは、仕事で忙しい一人暮らしの方にとって買い物の手間を減らせる便利なサービスです。

各社で料金・配送エリア・メニュー内容が大きく異なるため、比較せずに申し込むと割高なサービスを選んでしまう可能性がありますよね。

自分に合わないサービスを選ぶと、食費も時間も無駄になってしまいます。

この記事では、一人暮らしにおすすめの食材宅配サービス10選を紹介し、選び方のポイントを解説します。

<strong>まずは気になるサービスのお試しセットから試してみてください。</strong>
```

**合格ポイント**：
- 1文目（Problem）：メインKW「食材宅配」含む、読者メリット明示
- 2文目（Agitation）：リスク + 「〜ですよね」で共感（v4.1：「〜ですよね」は導入文のみ。本文では使わない）
- 3文目（Agitation）：放置した場合の追加リスク
- 4文目（Solution）：「この記事では〜」で統一
- 末尾：strong行動促し
- **直後にジャンプリンク付き比較表を配置**（v4.1で必須化）

## FAQの合格パターン

```html
<h3>Q. 一人暮らしでも食材宅配は元が取れますか？</h3>

食材を使い切るコツさえ押さえれば、一人暮らしでも元が取れます。

冷凍保存できる食材や、少量パックのコースを選べば食材のロスを減らせます（[Oisix公式](https://...)）。

自炊のガス・水道代や外食費を含めた総コストで比較してみてください。
```

**合格ポイント**：
- 質問語尾が「〜ですか？」で統一
- 回答の結論から始まる
- 数値・事実に出典URL併記（`[出典名](URL)` 形式）
- 2〜3文で完結

## まとめの合格パターン（v4.1で大幅緩和）

⚠️ **v4.1：strong要約・strong行動促し文は不要。** 自然な締めくくりを書く。

```html
<h2>まとめ：一人暮らし向けの食材宅配を試して食生活を快適にしよう</h2>

食材宅配サービスは各社で料金・送料・配送エリアが異なるため、一人暮らしの生活リズムに合ったサービスを選ぶのが重要です。

お試しセットを活用すれば、少ない負担で味と使い勝手を確認できます。

気になるサービスの公式サイトで郵便番号を入力し、対象エリアかどうかを先に確認してみてください。
```

**合格ポイント**：
- まとめH2の見出しに行動促しが含まれている
- 3〜5文で短く締める
- 本文の繰り返しではなく新しい角度で要約
- 「いかがでしたか」等のAI定型で終わっていない
- strong要約・strong行動促し文は不要（v4.1）
