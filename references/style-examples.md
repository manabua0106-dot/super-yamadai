## 1. 情報ゼロ文（ゴミ文章）の対比 ⭐最頻・最優先

**判定基準（§E-12-a）**：その文を消して読者が失う情報がゼロなら書かない。言い換え・当たり前の総括・トートロジーは全部これに該当する。

| NG（実記事でManabuさんが削除・修正した型） | 対処 |
|---|---|
| 味の好みは人それぞれで、「まずい」と感じる方がいるのも事実です。 | 削除。代わりに「なぜまずいと感じるか」の原因（薄味設計・週替わりおまかせ等）を書く |
| この口コミのように、産後で動けない時期に頼る方もいます。 | 削除（blockquoteの再説明。読者は直前に読んでいる） |
| 特に副菜のボリュームを重視する方には、少し寂しく感じるかもしれません。 | 削除（直前の「量が物足りない」の言い換え） |
| 食べ応えを重視する方は工夫が必要です。 | 削除（直前の対処ulの総括。ulが答えを出し終えている） |
| どこまで気にするかは人それぞれです。 | 削除（何も言っていない） |
| 〜方の毎日を楽にしてくれます。／いつでも温かい食事を用意できる安心感があります。 | 削除（既出内容の言い換え総括・学び43） |
| 料金は各社で違います。／品揃えは3社の大きな違いです。 | 削除して、何がいくら違うかを具体名・数字で書く |
| 目的に合ったサービスがあります。／食卓も変わります。 | 「サービスごとに強みが違います」等、何がどうなるかを具体に（学び25） |

**書く前の検算**：1文ごとに「①消しても意味が変わらないか ②主語述語が具体か ③中学生が一発で像が浮かぶか ④既出と重複しないか」（§E-12-a）。

## 2. strong締めのNG→OK

| NG | 理由 | OK |
|---|---|---|
| 美味しさだけでなく健康面でも安心できるのが大きな魅力です。 | 感想止まり | 管理栄養士が献立設計に関与したメニューなら、栄養バランスを自分で考える手間が省けます。 |
| 生活にゆとりが生まれます。 | 抽象的 | 買い物にかかっていた時間を、家族と過ごす時間や自分の趣味に使えるようになります。 |
| おすすめです。 | 行動不明 | お試しセットで味と量を確認してから定期コースに申し込むと、合わない食事を避けられます。 |
| 想定外の出費を防げます。／物足りなさを防げます。 | 「防げます」定型は禁止（§E-2・2026-06-29） | 送料込みの1食あたり料金で比べると、自分の予算に合うサービスが見つかります。 |
| 公式サイトで確認してから申し込めば安心です。 | 当たり前・情報ゼロ | 公式サイトで郵便番号を入力すれば、対象エリアかどうか調べられます。 |
| 配送回数を減らすと効果的です。 | 「効果的」は完全禁止（学び42） | 一度にまとめて注文して配送回数を減らすと、送料をおさえられます。 |

**strong締めの大原則**（§D-5・§E-2）：
- 新しい1文を足さない。**既存の結論文**にstrongを付ける
- 付ける既存文がなければ**省略してよい**（埋めるための言い換え文が最悪）
- 本文のどの文とも内容重複させない

## 3. 口コミ解説のNG→OK（口コミ・評判記事用）

| NG | OK |
|---|---|
| 「おいしい」という良い口コミが多く見つかりました。（→直後にまた）しっかりした味付けで満足できたという声が寄せられています。 | 声の紹介は導入1文だけ。解説は「だしを効かせた和食中心の味付け」「カロリー・塩分計算で薄味でも物足りなくならない工夫」等の**新しい事実**に使う |
| 〜という声が目立ちます。／〜を評価する声も見られます。／声に分かれます。 | メタ説明をやめ事実を直接書く：「味をほめる人もいれば薄いと感じる人もいます」（学び35） |
| 悪い口コミをもとにデメリットを解説します。 | 「気になる口コミ」と書く（§A-7。「悪い口コミ」は使わない） |
| （X投稿者を）訪問リハビリの専門家は〜と評価しています。 | citeにない肩書き・属性を作らない（学び39）。「実際に食べた人も〜と投稿しています」 |

## 5. 文で流さず表・箇条書きにする（学び45・§D-3/D-4）

| 情報の形 | NG（文で流す） | OK |
|---|---|---|
| 対の情報（向く人/向かない人） | 「〜な方に向いています。一方で〜な方には…また〜な場合は…」と文を連ねる | 2列の表（左：向いている人／右：他社が向いている人） |
| プラン×価格 | 「三菜は10食3,900円で、五菜は10食4,880円で、定期の場合は…」 | コース×価格区分の表 |
| 確認項目・対処法3つ以上 | 「まず〜を確認し、次に〜も見て、さらに〜も」 | 誘導1文＋ul |

**ulのルール**（§D-3）：直前に「何のリストか」の誘導1文を必ず置く／li内に句点を入れない／誘導文フレーズは記事内で分散（同じフレーズ3回以上NG）。
**tableのルール**（§D-4）：tdは名詞句で簡潔に（「〜です／〜ます」調の文を入れない・学び30）／tdが20字超なら列分割を検討。

## 6. 文のつながり（ぶつ切り→接続で流す・§E-10）

```
NG（関係が見えない羅列）:
自分で野菜の種類を選ぶことはできません。
苦手な野菜が入ったり、使いたい野菜が届かなかったりする場合があります。

OK（接続詞で関係を示す）:
坂ノ途中では、自分で野菜の種類を選べません。
旬においしい野菜を詰め合わせた「おまかせ」で届くからです。
そのため、苦手な野菜が入ったり、使いたい野菜が届かなかったりする場合があります。
```

理由は「〜からです」、順接は「そのため」、逆接は「ただし」「それでも」、追加は「さらに」「また」。
