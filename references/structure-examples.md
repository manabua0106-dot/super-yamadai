## H2/H3構造の合格パターン

### 食材宅配 一人暮らし記事の例

```
H2: 一人暮らし向け食材宅配サービスの選び方
  H3: 1食分から注文できるか確認する
  H3: 送料込みの月額費用で比較する
  H3: 冷凍保存できる商品が多いサービスを選ぶ
  H3: 置き配や時間指定ができるか確認する
  H3: お試しセットで味と量を確認してから申し込む

H2: 一人暮らしにおすすめの食材宅配サービス10選
  H3: 1.Oisix｜1人分のミールキットが充実している
  H3: 2.ヨシケイ｜送料無料で毎日届けてもらえる
  ...

H2: 一人暮らしで食材宅配を利用するメリット
  H3: 買い物の往復時間がゼロになる
  H3: 栄養バランスを考えなくても整った食事が届く
  H3: 食費が毎月ほぼ一定額になる

H2: 一人暮らしで食材宅配を利用するときの注意点
  H3: 少量注文だと送料の負担が大きくなる
  H3: おかずの種類が偏らないようにコースを選ぶ
  H3: 冷凍庫の空きスペースを事前に確保する

H2: 一人暮らしの食材宅配に関するよくある質問
  H3: Q. 一人暮らしでも食材宅配は元が取れますか？
  H3: Q. 留守がちでも受け取れますか？
  H3: Q. 解約はいつでもできますか？

H2: まとめ：一人暮らし向けの食材宅配を試して食生活を快適にしよう
```

### 合格ポイント

- H3が目次だけで答えがわかるレベル
- H3の語尾が「確認する」「比較する」「選ぶ」「申し込む」と散らしてある
- 選び方は「判断基準」、メリットは「読者にとっての効果」、注意点は「失敗パターン」で角度が違う
- 特定サービス名指しが選び方・メリット・注意点に入っていない
- FAQ見出しの語尾が「〜ですか？」で統一されている
- まとめH2に行動促し（「試して食生活を快適にしよう」）が含まれている

## H2導入文の合格パターン

### 選び方H2の導入文（リスクから入る）

```
食材宅配サービスは各社で料金・配送エリア・メニュー内容が大きく異なります。

比較せずに申し込むと割高なサービスを選んでしまう可能性があります。

以下の5つのポイントを押さえておくと、自分に合ったサービスを見つけやすくなります。

<ol>
<li>1食分から注文できるか確認する</li>
<li>送料込みの月額費用で比較する</li>
<li>冷凍保存できる商品が多いサービスを選ぶ</li>
<li>置き配や時間指定ができるか確認する</li>
<li>お試しセットで味と量を確認してから申し込む</li>
</ol>
```

**合格理由**：1文目がリスク（各社で異なる）、2文目が具体的なリスク（割高になる）、3文目が解決策の予告

### メリットH2の導入文（メリット予告から入る）

```
食材宅配サービスを使うと、毎日の食事づくりにかかっていた時間と手間が大きく減ります。

忙しい一人暮らしの方ほど、切り替えた後の生活の変化を実感しやすいです。

以下の3つのメリットを具体的に紹介します。

<ol>
<li>買い物の往復時間がゼロになる</li>
<li>栄養バランスを考えなくても整った食事が届く</li>
<li>食費が毎月ほぼ一定額になる</li>
</ol>
```

**合格理由**：メリットセクションなのでリスクから入らず、メリットの予告から始まっている

### NG例

```
ここでは食材宅配サービスの選び方を紹介します。
```

**NG理由**：単なる宣言。読者にとってのリスクや必要性がない

## H2間の棲み分け合格パターン

| H2 | 角度 | 扱う内容 |
|---|---|---|
| 選び方 | 判断基準・比較方法 | 何を基準に選ぶか |
| サービス紹介 | 各社の特徴・スペック | 各社の具体的な情報 |
| メリット | 読者にとっての効果 | 使うと何が変わるか |
| 注意点 | 失敗パターンと対策 | 使って失敗しないために |
| FAQ | 本文未対応のニーズ | 本文で扱っていない疑問 |
