# 「改善 or 悪化」判定の標準フレーム

**目的**：単一指標で結論を出して論理破綻するのを防ぐ。
**起源**：2026-05-14 BlueWorksTax MTGで「悪化と思い込み補強ロジックを後付け」と指摘された事案。

---

## 結論

**「改善/悪化」という言葉を使う前に、必ず以下4ステップを通す**。

| ステップ | 内容 |
|---|---|
| 1 | データをフラットに記述（仮説・解釈なし） |
| 2 | 判定基準を明示（何の指標を・何と比較して） |
| 3 | 複数指標で評価（CPA・ボリューム・最終KPIの3点セット） |
| 4 | 「目標達成 or 未達」と「トレンド改善 or 悪化」を分離 |

---

## ステップ詳細

### ステップ1：データをフラットに記述

仮説・解釈を入れずに「いつから・いつまで・何が・どう変わったか」だけ書く。

❌ 「最近Google広告の数値が悪化している」
✅ 「Google広告（税務顧問）：4/17にKWマッチタイプを完全一致主体に変更。変更前30日間と変更後30日間で、CPA 5万円→2.5万円、表示回数 75,000→500、CV 3件→2件、CVR 0.4%→0.5%」

### ステップ2：判定基準を明示

「何を以って」改善・悪化と判定するか、宣言する。

| 基準 | 改善の定義 | 悪化の定義 |
|---|---|---|
| CPA基準 | CPAが下がった | CPAが上がった |
| ボリューム基準 | CV絶対数が増えた | CV絶対数が減った |
| 最終KPI基準 | アポ・受注が増えた | アポ・受注が減った |
| 効率基準 | CVRが上がった | CVRが下がった |
| 学習基準 | 配信機会が確保できている | 配信機会が枯渇している |

### ステップ3：複数指標で評価

最低3軸で評価し、判定が割れた場合はそれを明示する。

| 軸 | 結果 |
|---|---|
| CPA基準 | 改善（5万→2.5万） |
| ボリューム基準 | 悪化（CV3→2件） |
| 最終KPI基準 | 横ばい（アポ1件→1件） |

→ **総合判定**：「CPA効率は改善、ただしボリューム不足で目標未達。優先課題はボリューム回復」

### ステップ4：「目標」と「トレンド」を分離

| 観点 | 改善している | 悪化している |
|---|---|---|
| **目標達成度** | 達成 | 未達 |
| **トレンド** | 上昇傾向 | 下降傾向 |

| 状態 | 説明 | 例 |
|---|---|---|
| 目標達成 × 上昇 | 順調 | 月予算消化100%・CV増加 |
| 目標達成 × 下降 | 警戒 | 目標は達成だがCV単価が悪化中 |
| 目標未達 × 上昇 | 改善中 | 目標未達だが直近2週間でCV増 |
| 目標未達 × 下降 | 危険 | 目標未達かつ悪化進行中 |

→ **「目標未達」だけで「悪化」と表現しない**。トレンドが上向きなら「改善中だが目標未達」と書く。

```
# 数値判定サマリ（YYYY-MM-DD時点）

## 結論
- CPA基準：[改善 / 悪化 / 横ばい]（○○円 → ○○円、△△％）
- ボリューム基準：[改善 / 悪化 / 横ばい]（○件 → ○件）
- 最終KPI基準：[改善 / 悪化 / 横ばい]（○件 → ○件）
- 目標達成度：[達成 / 未達]（目標○○に対し実績○○、達成率△△％）
- トレンド：[上昇 / 横ばい / 下降]
- **総合判定**：[ひと言で]

## データ（フラット記述）
（解釈なしで数値変化を記述）

## 比較期間
- 期間A：YYYY-MM-DD ～ YYYY-MM-DD
- 期間B：YYYY-MM-DD ～ YYYY-MM-DD
- 比較理由：（なぜこの期間で比較するか）
```

## アンチパターン

| ❌ NG表現 | ✅ 修正 |
|---|---|
| 「悪化しているように見えます」 | 「CPA基準では改善（○○円→○○円）、ボリューム基準では悪化（CV○件→○件）」 |
| 「目標未達なので悪化です」 | 「目標未達だが、直近2週間のトレンドは改善中」 |
| 「改善傾向にあります」 | 「直近30日のCPAは平均○○円で、前30日比△△％改善」 |
| 「全体的に良くなっています」 | 「CPA・CVR・CV絶対数の3指標すべてで改善」 |
