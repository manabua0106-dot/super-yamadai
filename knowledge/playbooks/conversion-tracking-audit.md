# コンバージョン計測監査チェックリスト

**目的**：広告配信の判断を下す前に、計測が正しく行われているかを確認する。
**原則**：**計測がおかしければ、その上のすべての判断がおかしくなる**。広告判断より計測修正が先。

---

## 結論

PC/SP差分析・媒体間比較・改善提案の前に、必ず以下5項目を監査する。

| # | 項目 | 確認方法 |
|---|---|---|
| 1 | CV定義の一致 | 広告管理画面 / GA4 / 営業実績の3点照合 |
| 2 | タグ発火 | デベロッパーツール / Tag Assistant |
| 3 | デバイス別の発火状況 | 管理画面のデバイス別CV数 |
| 4 | 計測外CVチャネル | 電話・LINE・メール直接 |
| 5 | クロスデバイス・重複 | 設定確認 + 数値の整合性 |

---

## 1. CV定義の一致

### チェック項目

- [ ] Google広告のCV定義（フォーム送信？資料DL？電話？）が明確か
- [ ] Meta広告のCV定義が明確か
- [ ] 媒体間でCV定義が揃っているか（フォーム送信を片方は計上、もう片方は計上していない、等がないか）
- [ ] 営業側の「実際の問い合わせ件数」と一致しているか
- [ ] CV値（金額）が設定されているか（マイクロCVや段階別CVなら必須）

### よくある問題

- 「問い合わせフォーム送信」をCVとしているが、実際の営業側のリード数と乖離
- 媒体A：フォーム送信 / 媒体B：フォーム到達 でCV基準が違う
- LP複数あって、計測タグが入っていないLPがある

---

## 2. タグ発火

### チェック項目

- [ ] 主要LP全てにGoogle広告タグが入っている
- [ ] Meta Pixelが入っている
- [ ] GA4タグが入っている
- [ ] CV発火イベント（フォーム送信完了画面 or thanks page）でタグが発火する
- [ ] サンクスページ直接アクセスでCV計上されないか（直接URLで二重計上防止）
- [ ] iOSでもAndroidでも発火するか

### 確認方法

- Chrome DevTools → Network → 該当URLでタグリクエスト確認
- Google Tag Assistant（Chrome拡張）
- Meta Pixel Helper（Chrome拡張）
- GA4 DebugView

### よくある問題

- GTMの公開漏れ
- フォーム送信時にAjaxで送信完了する（ページ遷移なし）→ thanks pageが表示されずタグ未発火
- iOSでITPの影響でCookie失効
- LP変更時にタグが消えた

---

## 3. デバイス別の発火状況

### チェック項目

- [ ] Google Ads「目標」 → コンバージョンアクション → デバイス別CV数を確認
- [ ] PC・SP・タブレットそれぞれでCVが発生しているか
- [ ] あるデバイスでCVが極端に少ない場合、計測欠落の可能性を疑う

### よくある問題

- SPでJSが正しく動かず、フォーム送信時のCVタグが発火しない
- SP特有のページ（AMPページ等）にタグが入っていない
- 表示速度が遅すぎて、サンクスページ到達前にユーザー離脱

### 判定基準

- SP CV数 / PC CV数 = SPクリック数 / PCクリック数 から大きく乖離していたら計測の可能性
- 例：クリック数比 SP:PC = 2:1 なのに CV数比 SP:PC = 0:1 → SP計測欠落の疑い濃厚

---

## 4. 計測外CVチャネル

### チェック項目

- [ ] 電話番号がLPに記載されているか → 電話CV計測の有無
- [ ] LINE @ がLPに記載されているか → LINE経由CVの計測有無
- [ ] メール直送（info@等）の有無 → メール送信CVの計測有無
- [ ] チャットボット → チャット開始 / 完了 のCV計測有無

### B2B特有の注意

税理士・経理代行・士業のような信用前提の業種では、**電話・メール直送が主要CVチャネル**になることが多い。

| 業種 | 主要CV | 計測難易度 |
|---|---|---|
| EC | 購入完了 | 容易 |
| SaaS | 無料登録・トライアル | 容易 |
| BtoBリード獲得 | フォーム送信 | 容易 |
| **士業・コンサル** | **電話・メール直送・フォーム** | 中（電話CV設定要） |
| 不動産・自動車 | 来店予約・電話 | 難（オフライン連携） |

### 電話CV計測の方法

- Google広告「通話コンバージョン」（広告内・LP内のクリック）
- 番号ポータビリティ系（Coxsil等）
- 着信のみ追跡できるサービス

---

## 5. クロスデバイス・重複

### チェック項目

- [ ] Google広告のクロスデバイスCV計上設定確認（デフォルトはON）
- [ ] 同一ユーザーの複数CV（重複計上）の有無
- [ ] CV数 vs 営業側の実数の差が30%以上なら異常

### クロスデバイスCVの注意

- SPで広告クリック → PCで後日CV → Googleはこれを「PC CV」として計上することがある
- → SP CVが過小評価される構造
- 解決：「デバイス別」で分けず「アシスト含む」で見る or アトリビューション分析

## アンチパターン

| ❌ NG | ✅ 修正 |
|---|---|
| 計測未確認のままLPO・入札調整を実施 | 計測監査を先に実施 |
| 「SP CV少ない → SP LPが悪い」と即断 | まず「SPで計測欠落していないか」を確認 |
| 電話CV未設定なのに「フォームCVだけで判断」 | 電話CV設定 or 営業実数とのギャップを補正 |
